## Global Constraints

- 束ねキーは item.role(児童/保護者/本人)で、見出し文言では束ねない。見出しはサイトごとに違うため。
- 単一プロファイル時と役割が1種しかないページでは現行 UI・現行計画を変えない(既存 corpus 約265件への波及ゼロ。新経路は child と guardian の行が両方あり profiles が2件以上のときだけ開く)。
- 住所は従来どおり共通の1つ(参加者側の住所行に適用)。役割ごとの住所分離は今回やらない。
- 初期割当ては児童=self=1人目、保護者=2人目(あれば)。ユーザーは変更できる。
- プロファイル値は外部に送らない既存不変条件を守る。計画と選択 ID 以外の送信は増やさない。
- src/core は DOM 非依存のまま。コメントにタスクIDを書かない。CHANGELOG.md はユーザー作業中(未コミット)なので触らない。コミットは自分の変更ファイルだけ明示指定(git add -A 禁止)。
- docs/*.md は CP932 で表現できる文字のみ(em dash U+2014 禁止、横棒は ― を使う)。
- 検証: Task 1 は planner 単体で赤→緑。Task 2 で make check / make eval を緑に戻す。単一プロファイルの既定経路は値が変わらないため pin は動かないはず。動いたら理由を報告に書く。
