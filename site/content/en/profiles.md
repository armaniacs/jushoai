# Profiles

A profile is the information about one person to fill in, such as yourself or a family member. You can register up to 10 profiles. Registered values are stored only inside this browser.

## Register a profile

Open the extension's settings page and choose `プロファイル` (profiles) in the left menu.

| Item | Notes |
|---|---|
| Name | A label for the profile, such as yourself or family. It helps you pick one later. |
| Family name and given name | |
| Family name and given name in katakana (セイ・メイ) | Full-width katakana. Hiragana or half-width input is converted to full-width katakana when you save. |
| Family name and given name in romaji | For forms with romaji fields. Optional. |
| Birthday | Can also fill fields split into year, month, day or era. Optional. |
| School, faculty and department | Optional. |
| Email address | |
| Phone number | 10 to 11 digits. Hyphens are removed. |
| Gender | For gender dropdowns and radio buttons. Optional. |

## Use several profiles

- Add: use the add button. You cannot add more once you have 10.
- Duplicate: copy an existing profile and change only what differs.
- Delete: remove a profile you no longer need.

When you click `JushoAI で入力` (fill with JushoAI) on a form, you can choose which profile to use at the top of the preview. The list updates when you choose another one.

## How profiles relate to addresses

An address can be tied to the profile that uses it. When you switch profiles, the tied address is selected automatically. See [Addresses](/en/guides/addresses/) for details.
