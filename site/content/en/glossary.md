# Glossary

The meanings of five terms the guides assume. Each guide's own explanation is authoritative for usage.

## Profile

The information about a "person" used for filling. You can register up to 10, such as yourself and family, and the values stay only in this browser. See [Profiles](/en/guides/profiles/).

## Address

The place information used for filling, such as postal code, prefecture, city, street, and building. It is linked to the profile in use, and switching profiles automatically selects the linked address. See [Addresses](/en/guides/addresses/).

## Preview

The list shown for review before filling, after pressing "Fill with JushoAI". Pressing the apply button fills only the fields without a notice. See [Popup and filling](/en/guides/popup-and-fill/).

## AI classification

Letting the configured AI classify only the fields that rules could not judge. The AI only classifies and never creates the values to fill. Only field metadata is sent, never your profile values. See [AI provider setup](/en/guides/ai-providers/) and [Privacy and what is sent](/en/guides/privacy/).

## Audit log

The record kept on your device every time an AI is called. On the settings page, `通信の監査ログ` (communication audit log) lets you check the list, download a TSV, or delete the log. Each record contains the prompt sent to the model and its answer. Profile values are never recorded. See [Privacy and what is sent](/en/guides/privacy/).
