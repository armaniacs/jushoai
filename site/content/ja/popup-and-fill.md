# フォームへの入力とツールバー

## ツールバーのアイコン

ブラウザのツールバーにある JushoAI のアイコンを押すと、「登録内容の確認」が開きます。

- 登録済みのプロファイルと住所の一覧
- 現在選ばれているプロファイルと住所を示す「使用中」バッジ
- 住所ごとの「使う人」（特定のプロファイルに紐付けていない住所は「共通」）
- 右上の歯車アイコン、または未登録案内の「設定を開く」から設定ページへ移動
- 「AI で分析」を押すと、開いているタブのフォームで分類からプレビューまでを開始（フォームがないタブなどでは理由を表示、未登録時は設定ページを開く）
- **「ゲストで入力」**を押すと、設定に保存しない 1 回限りの入力パネル（`ゲストで入力（保存しません）`）を開いているタブに表示（通常のプロファイルや住所が未登録でも使えます。詳しくは [シーン別の使いこなし](./scenarios.md)）

プロファイルや住所が未登録のときは、登録を案内する表示が出ます。また、画面表示自体は日本語専用ですが、ポップアップの末尾には英語話者向けの 3 手順案内（`How to use / 使い方（English）`）を表示しています。

## フォームで入力する

氏名や住所などの入力欄が複数あるフォームの近くに、「JushoAI で入力」ボタンが出ます。横のバッジは AI の状態です（バッジを押すと状態に応じた案内が開きます）。ボタンは入力欄と重ならない位置を選び、背景は半透明（ホバーやフォーカス時は不透明）のため重なっても下の欄が見えます。また、ボタン、プレビュー、ダイアログは OS のダークモード設定に自動で追従します。

### ボタンを移動する

ボタンが入力欄に重なって邪魔なときは、ドラッグで好きな場所にどかせます。マウスでつかんで動かすほか、フォーカスして矢印キーでも動かせます（`Shift` を押すと大きく動きます）。

- 移動した位置は、スクロールやリサイズの後も保たれます（画面の外にはみ出さないよう収まります）
- 小さな動きはクリックとして扱うため、押すつもりが動いてしまう心配はありません

```youtube 9gHt4KeipHc
ボタンのドラッグ移動（約20秒）
```

[YouTube で動画を見る（約20秒）](https://www.youtube.com/watch?v=9gHt4KeipHc)

### プレビューで確認して入力する

1. 「JushoAI で入力」を押します（AI を有効にしていてルールで判定できない欄がある場合は、送信前に「AI判定で送る内容」が開きます）。
2. プレビュー（「入力内容の確認」）が開きます。上部で使うプロファイルと住所を選べます（2 件以上のプロファイルがあり、児童向け・保護者向けの欄が両方あるフォームでは「児童用」「保護者用」が出ます。また、同じフォームへの再訪時は前回と同じ行が「前回と同じ」に折りたたまれ、「前回と同じ欄を表示」で開けます。詳しくは [シーン別の使いこなし](./scenarios.md)）。
3. 先頭にある「x / y 欄に入力できます（承認後に注入します）」の集計と、欄・値の一覧を確認します。注記が付いた欄には入力しません。建物名の文字数超過や未登録項目の補助候補がある欄には、チェックボックス（`略記して入れる`・`補助候補を入れる`）が出ます。
4. 「入力する」を押すと、注記の付いていない欄（およびチェックを入れた補助候補）に入力します。

| 注記 | 意味 |
|---|---|
| 入力済みのため上書きしません | すでに値がある欄です。 |
| 文字数を超えるため入力しません | 最大文字数を超える値は、切り詰めずに入力しません。 |
| 欄のパターンと合わないため入力しません | 値が欄に期待される形式と合いません。形式の不一致であり、文字数の問題ではありません。 |
| 一致する選択肢がないため入力しません | プルダウンに該当の項目がありません。 |
| プロファイルに値がないため入力しません | プロファイルにその欄の値が未登録です。 |

AI が分類した欄には「AI判定」の印が付きます。分類が違う欄は「直す」から修正できます。入力せずに閉じたいときは Esc キーか「キャンセル」を押します。1 つの欄だけに入力する方法は [1 欄入力・取り込み・移行と管理](./shortcuts-and-tools.md) を参照してください。

入力が終わると（戻せる欄がある場合や一部が未適用になった場合）、パネルは **「入力結果」** に切り替わります。

- 「適用済み x / y件（未適用 z件）」と状態別の件数内訳を表示します。
- 直前に JushoAI が入れた欄を空状態に戻したいときは「元に戻す」を押します（入力後に自分で書き足した欄は保護のため触りません）。
- 「内訳をissueで報告」を押すと、件数内訳と最小化した URL 等だけを入れた GitHub Issue の下書きを開きます（プロファイルの値や欄の文字列は送りません）。
- 適用時に欄が消えている・外れている等で未適用の失敗が発生したときは、フォーム上のボタンにも「一部のみ適用（x/y件）」の表示が残ります。

## 起動しない URL

表計算やメールなど、入力の補完が無関係なページでは、ボタンが出ると邪魔になります。設定ページの「起動しないURL」に URL を登録すると、その URL とその配下のページでは JushoAI が動きません。

1. 設定ページの「起動しないURL」を開きます。
2. URL を入力して「追加」を押します。
3. 「保存」を押します。

- ページからも登録できます。「JushoAI で入力」ボタンの右上の「X」（`このボタンを隠す`）を押すとボタンが隠れ（リロードまで）、ダイアログが出ます。「このページだけ」か「この配下全体」（ルート URL の場合は「このサイト全体」）を選び、「起動しないURLに登録する」を押すと、設定ページを開かずに登録できます
- このダイアログは 15 秒後に自動で閉じます。ポインターを重ねている間やダイアログ内のボタンにフォーカスしている間は閉じません。隠れたボタンをすぐ戻したいときは「元に戻す」を押します
- 登録が成功すると、ダイアログには「解除は設定ページの『起動しないURL』から。」という案内と、直前の登録を取り消す「登録を取り消す」ボタンが現れます。押すと登録が削除され、隠れたボタンも戻ります
- ダイアログの「この配下全体」で登録される範囲は、オリジン（`https://example.com` の部分）と第 1 パスセグメントまでです。例: `https://example.com/foo/bar` のページでは `https://example.com/foo/` が登録され、その配下のページが対象になります。オリジンの直下では、サイト全体を表す URL が登録されます
- 例: `https://docs.google.com/spreadsheets/` を登録すると、その配下のスプレッドシートでは動きません。同じホストの `https://docs.google.com/document/` は対象外です
- 一致は、オリジンが同じで、登録したパスと同じかその配下かどうかで判定します（大文字小文字は区別しません）。例: `https://example.com/pay` は `https://example.com/payment` と一致しません
- 保存すると、開いているページにもすぐ反映されます。対象のページではボタンが消えます
- 100 件まで登録できます。`http://` または `https://` で始まる URL だけを登録できます

一覧から削除して「保存」を押すと、元どおり動くようになります。

## AI で分析

ルールで判定できなかった欄があるときは、プレビューの「AI で分析」で、設定した AI に分類させ直せます。なお、プレビューの中から「AI で分析」を実行した場合は、「AI判定で送る内容」を再度開かずに除外していない欄を送り直します。設定方法は [AI プロバイダの設定](./ai-providers.md) を参照してください。

再分析を実行すると「入力する」の横に「開発に報告する」チェックボックスが現れます。チェックを入れて「入力する」を押すと、公開の GitHub Issue 作成画面が開き、再分析で入力できるようになったフォームを知らせられます（送られるのは最小化した URL と入力欄のメタデータ・分類結果だけで、プロファイルの値は送りません）。
