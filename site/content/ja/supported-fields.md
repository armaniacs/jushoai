# 対応する入力欄

JushoAI が対象にするのは、text・email・tel・search の入力欄と、select（プルダウン）です。ラジオボタンは、性別と年代のグループだけ対応します。

## 入力できる欄

| 分類 | 欄 | 備考 |
|---|---|---|
| 氏名 | 姓、名、姓名（1 欄） | 1 欄のときは、例示から、姓名の間を空けるか詰めるかを選びます。 |
| フリガナ | セイ、メイ、フリガナ（1 欄） | 全角カナ、ひらがな、半角カナに対応します。 |
| ローマ字 | 姓、名、姓名（1 欄） | プロファイルにローマ字を登録している場合です。 |
| 生年月日 | 年、月、日、元号 | 西暦と元号に対応します。 |
| 性別・年代 | プルダウン、ラジオボタン | 年代は、生年月日から求めます。 |
| 学校 | 学校名、学部・学科 | |
| 連絡先 | メールアドレス、電話番号 | 電話番号は、1 欄と、3 つに分かれた欄に対応します。 |
| 郵便番号 | 1 欄、前半と後半の 2 欄 | ハイフンの有無は、例示と最大文字数から決めます。 |
| 住所 | 都道府県、市区町村、番地、建物名、住所全体（1 欄） | 都道府県のプルダウンは、表記ゆれにも対応します。 |
| 英語住所 | 国、住所 1〜4、郵便番号 | 住所に英語住所を登録している場合です。 |

## 対応していない欄

- チェックボックス、日付入力、ファイルなど、上記以外の種類
- 性別・年代以外のラジオボタン
- 非表示の欄、送信ボタン、`readonly` と `disabled` の欄

判定できない欄には、入力しません。判定の仕組みは [対応するフォームと仕組み](/guides/how-it-works/) にあります。

## 対応してほしいフォームがあるとき

入力できなかったフォームは、ページ下部の導線から GitHub の Issue で知らせてください。フォームの URL と、入力されなかった欄を書いていただけると、確認しやすくなります。
