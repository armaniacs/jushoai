# 対応する入力欄

JushoAI が対象にするのは、`text`・`email`・`tel`・`search`・`date` の入力欄と、`select`（プルダウン）です。ラジオボタンは、性別と年代のグループのみ対応します。

## 入力できる欄

| 分類 | 欄 | 備考 |
|---|---|---|
| 氏名 | 姓、名、姓名（1 欄） | 1 欄のときは、例示から姓名の間を空けるか詰めるかを選びます。児童用・保護者用など役割別の欄にも対応します（[シーン別の使いこなし](./scenarios.md)）。 |
| フリガナ | セイ、メイ、フリガナ（1 欄） | 全角カナ・ひらがな・半角カナに対応します。未登録時は端末内の読み辞書から補助候補を出せます。 |
| ローマ字 | 姓、名、姓名（1 欄） | プロファイルにローマ字を登録している場合です。1 欄では「名 姓」の順で入れます。 |
| 生年月日 | 年、月、日、元号、1 欄型（`type=date` を含む `YYYY-MM-DD`） | 西暦と元号に対応します。ラベルなしの年・月・日プルダウンも選択肢の文言から判定します。 |
| 性別・年代 | プルダウン、ラジオボタン | 英語の選択肢（Male / Female）にも対応します。年代は生年月日から計算します。 |
| 学校・塾 | 学校名、学部・学科、学校の学年、塾名 | 英語の `Institution` 等にも対応します。 |
| 会社・勤務先 | 会社名、会社名（フリガナ）、会社の部署、役職 | プロファイルに任意項目として登録している場合です。 |
| 連絡先 | メールアドレス、電話番号（1 欄・3 分割欄）、FAX 番号 | 電話語のない 3 分割の緊急連絡先欄にも対応します。FAX 番号にはプロファイルの電話番号を流用します。 |
| 郵便番号 | 1 欄、前半と後半の 2 欄 | ハイフンの有無は、例示と最大文字数から決めます。 |
| 住所 | 都道府県、市区町村、番地、建物名、住所全体（1 欄） | 都道府県は表記ゆれと数字コード照合に対応します。建物名の文字数超過時は略記候補、未登録時は郵便番号辞書から補助候補を出せます。 |
| 英語住所 | 国、住所 1〜4、郵便番号 | 住所に英語住所を登録している場合です。 |

## 対応していない欄

- チェックボックス、ファイル、複数行テキスト（`textarea`）など、上記以外の種類
- 性別・年代以外のラジオボタン
- 非表示の欄、送信ボタン、`readonly` と `disabled` の欄

判定できない欄には入力しません。判定の仕組みは [対応するフォームと仕組み](./how-it-works.md) にあります。

### 意図的に入力しない欄（誤入力を防ぐため）

次の欄は、入力できる種類であっても、誤入力やフォームの不具合を防ぐためにあえて入力対象から外しています。

- **サイト内検索窓**: ラベルのない `q`・`query`・`keyword` 等は検索欄とみなし、氏名などと誤認して埋めないようにします。
- **塾名などの検索補助窓**: 選択式の塾名欄などで、見た目の絞り込み用テキスト欄だけに入力すると裏の送信値が入らないため、入力しないようにしています。
- **出身校の絞り込み用の都道府県・市区プルダウン**: 学校を選ぶための絞り込み欄が、お住まいの住所欄として誤分類されるのを防ぎます。
- **前の選択に応じて後から選択肢が出る連動プルダウン**: 開いた時点で該当する選択肢がないため、「一致する選択肢がないため入力しません」と警告を出して安全に止めます。

## 対象外とするもの

欄の種類以外に、次を対象外としています。

| 項目 | 理由 | 代替手段 |
|---|---|---|
| クレジットカード番号・口座番号などの機微情報 | プロファイルに保存するのは日常の連絡先の情報に限るため | 手入力、またはパスワードマネージャーの機微情報欄 |
| 認証コード・SMS 確認コード・2 段階認証 | 安全に関わる情報のため | 手入力 |
| ページ読み込み時の自動入力 | プレビュー確認なしに注入しないため | 「JushoAI で入力」のボタンから実行 |
| クロスオリジン iframe 内のフォーム | 調査の結果、対象外としています（埋め込みウィジェットなど） | ページ自体の URL を開いて入力 |
| PDF・印刷帳票 | ブラウザのフォーム外のため | 端末側の入力機能 |

送信するデータの範囲は [プライバシーと送信データ](./privacy.md) にあります。

## 対応してほしいフォームがあるとき

入力できなかったフォームは、ページ下部の導線から GitHub の Issue で知らせてください。フォームの URL と、入力されなかった欄を書いていただけると、確認しやすくなります。
