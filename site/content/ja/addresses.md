# 住所

住所は、プロファイルとは別に、何件でも登録できます。自宅、勤務先、実家のように使い分けられます。

## 登録する

設定ページの左メニューで「住所」を選びます。

| 項目 | 備考 |
|---|---|
| 名前 | 自宅、勤務先などの呼び名です。 |
| 郵便番号 | 7 桁です。 |
| 都道府県 | 一覧から選びます。 |
| 市区町村 | |
| 番地 | |
| 建物名・部屋番号 | 任意です。 |
| 英語住所 | 国名、州・地域、市、番地、建物名、郵便番号。英語の欄があるフォーム用で、任意です。 |

## プロファイルと紐付ける

住所ごとに、使うプロファイルを選べます。

- 特定のプロファイル: そのプロファイルを使うときだけ、候補になります。
- 共通: どのプロファイルでも候補になります。

フォームでプロファイルを切り替えると、紐付けた住所が自動で選ばれます。同じ住所を複数の人で使うときは、「共通」にします。

## フォームで住所を選ぶ

住所を複数登録している場合は、プレビューの上部で、使う住所を選べます。選び直すと、一覧が更新されます。
