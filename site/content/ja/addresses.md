# 住所

住所は、プロファイルとは別に最大 10 件まで登録できます。自宅、勤務先、実家のように用途ごとに登録して使い分けられます（10 件に達すると追加できません）。

自分の住所を入れずに動作を試したいときは、設定ページ上部の案内から「架空の住所を作って試す」（プロファイルも未登録のときは「架空の名前と住所を作って試す」）でサンプルの住所を作って試せます。

## 登録する

設定ページの左メニューで「住所」を選びます。入力後、「保存」を押すと住所だけを保存できます（プロファイルがまだ未登録でも保存でき、その場合は「プロファイルを入力する」の案内が出ます）。

| 項目 | 備考 |
|---|---|
| 使うプロファイル | 「共通（どのプロファイルでも使う）」または特定のプロファイルを選びます。 |
| 名前（自宅・勤務先など） | 住所の呼び名です（必須）。 |
| 郵便番号 | 7 桁の数字です（国内住所では必須。ハイフンを含めても保存時に数字 7 桁になります）。 |
| 都道府県 | 一覧から選びます（国内住所では必須）。 |
| 市区町村 | 国内住所では必須です。 |
| 番地 | 国内住所では必須です。 |
| 建物名・部屋番号（任意） | 任意です。フォームに建物名の専用欄がない場合は、番地の後ろに半角スペースで続けて入ります。 |
| 英語住所（任意） | 国名、建物名、番地、市、州・地域、英語の郵便番号を半角英数で入力します。英語の欄があるフォーム用で任意です（英語住所を入力する場合は国名が必須。国名を入れると国内住所の各項目は任意になります）。 |

不要な住所は「この住所を削除」で削除し、「住所を追加」で増やせます。開いているフォームに入力済みの住所を取り込んで下書きを作りたいときは、「フォームから取り込む」も使えます（[1 欄入力・取り込み・移行と管理](./shortcuts-and-tools.md)）。

## プロファイルと紐付ける

住所ごとに「使うプロファイル」を選べます。

- **特定のプロファイル**: そのプロファイルに切り替えたとき、自動で優先候補として選ばれます。
- **共通（どのプロファイルでも使う）**: どのプロファイルを使っているときも共通の候補になります。

フォームのプレビューでプロファイルを切り替えると、紐付けた住所（または共通の住所）が自動で選ばれます。同じ住所を家族で共用するときは、「共通（どのプロファイルでも使う）」にしておくと便利です。

## フォームで住所を選ぶ・入力の補助

住所を複数登録している場合は、プレビューの上部にある「住所」の選択欄で使う住所を切り替えられます。選び直すと、一覧が即座に更新されます。

また、住所の入力ではプレビュー上で次の補助候補が使えます（いずれも既定ではチェックが外れており、利用者が明示的にチェックを入れたときだけ入力します）。

- **郵便番号からの補助候補（`補助候補を入れる`）**: 住所の都道府県や市区町村が空のままでも（「ゲストで入力」などで未入力のとき）、郵便番号が入っていれば、端末内の郵便番号辞書（通信なし・AI なし）から都道府県や市区町村の候補を出します。辞書は郵便番号の上 3 桁単位で、複数の市区町村にまたがる番号では都道府県だけを出して市区町村は警告のままにします。いまの辞書は東京 23 区と主な都市のシードで、全国版への更新手順は[リリース手順](https://github.com/armaniacs/jushoai/blob/main/docs/release.md)にあります。データの出典は[ライセンス](./license.md)を参照してください（[シーン別の使いこなし](./scenarios.md)）。
- **建物名が長すぎるときの略記候補（`略記して入れる`）**: フォームの文字数制限（`maxlength`）より建物名が長いとき、JushoAI は勝手に切り詰めず警告を出したうえで、ルールに沿った短縮候補（例: `マンション` → `邸`、`ビルディング` → `ビル`）を提案します。チェックを入れたときだけ略記で入力します（[シーン別の使いこなし](./scenarios.md)）。
