# プライバシーと送信データ

## 送るもの、送らないもの

AI を設定しない限り、外部への通信はありません。

外部へ送るのは次の場合だけです。ブラウザ内蔵 AI 以外のプロバイダを設定し、「JushoAI で入力」または「AI で分析」を押したときです。送るのは、ルールで判定できない欄の情報です。設定ページの「接続テスト」では、合成したテスト用の 1 欄だけを送ります。

- 欄を区別するための内部 ID（`jai-N` の形式で生成する ID で、HTML の `id` 属性とは別のものです）
- `type`、`maxLength`
- `name`、`htmlId`（HTML の `id` 属性）、`label`、`placeholder`、見出し（`nearby`）。この 5 つは、それぞれ 80 文字までに切り詰めます。

次のものは送りません。

- プロファイルの値
- 欄に入っている値
- `select` の選択肢
- `autocomplete`、`pattern`

`label` や見出しは、ページ上の文言です。ページに表示されている個人情報が含まれることがあります。

## 送信前の確認と自動除外

AI が有効で、ルールで判定できない欄があるときは、AI に送信する前に「AI判定で送る内容」パネルが開きます。

- 実際に送られる欄のメタデータを確認してから「AI判定する」を押すまで、何も送信しません。
- ページ上のラベルや見出しに氏名・住所・電話番号・メールアドレス・郵便番号らしい文言が含まれる欄には「（要確認）」が付き、既定で「送らない」にチェックが入ります。
- 「ルールのみで入力する」を押すか、Esc キー等で閉じると何も送らずにルールだけで入力を進めます。
- プレビューの「直す」で教えた欄（覚えた対応付け）は、自動的に送信対象から除外され、AI に送られることはありません。

## 通信が起きるとき

通信は、「JushoAI で入力」「AI で分析」を押したときと、設定ページで「接続テスト」を実行したときだけです。ページを開いただけでは、AI プロバイダへの通信は起きません。バッジの状態の確認は、保存された設定と権限を見るだけで、通信しません。

送信先のホストは、保存時に名前解決の結果まで検証し、解決先が内部ネットワークのアドレス（NAT64 や 6to4 などの IPv6 変換プレフィックスを含む）に解決される・解決を確認できないときは保存を拒否します。呼び出しの直前にも解決先を再確認し、内部アドレスへの解決や解決できない結果ではその呼び出しを行わず、残りの欄はルールだけで続けます。ホスト名の字句チェックは引き続き適用されます。解決結果は呼び出しごとに取り直し（per-call）、前の呼び出しの結果は次の呼び出しに持ち越しません。検証と実際の接続は別々の名前解決であるため、その間に解決結果が変わる（DNS rebinding）場合を完全には排除できません。

## 監査ログ

AI を呼び出すたびに、記録を端末内に残します。設定ページの「通信の監査ログ」で、一覧の確認、ダウンロード、削除ができます。ブラウザ内蔵 AI と接続テストも記録します。

| 列 | 内容 |
|---|---|
| `id` | 連番 |
| `created_at` | 記録した日時（ISO 8601） |
| `provider` | `openai`、`gemini`、`built-in` のいずれか |
| `host` | 送信先のホスト。ブラウザ内蔵 AI は空 |
| `model` | モデル名。ブラウザ内蔵 AI は空 |
| `purpose` | `classify`（入力時の分類）または `connection-test`（接続テスト） |
| `page_url` | 入力したページのオリジン（スキーム・ホスト・ポート）のみ。パス・クエリ・フラグメントは含みません。接続テストは空 |
| `field_count` | 送った欄の数 |
| `chunk_index` / `chunk_count` | 20 欄ずつに分割して送ったときの位置。分割しないときは空 |
| `result` | `success`、`auth-error`、`http-error`、`network-error`、`invalid-response`、`error` |
| `http_status` | HTTP ステータス。通信できなかったときと内蔵 AI は空 |
| `retried` | 互換リクエストへ再試行したか |
| `duration_ms` | 呼び出しの所要時間（ミリ秒） |
| `request` | モデルに送ったプロンプトの全文。欄のメタデータだけを含む |
| `response` | モデルの応答。2,000 文字を超えるときは先頭だけを残し、末尾に `…` を付けます |

一覧は新しい順に並び、各記録の行には対象のページ URL が表示されます。各記録を開くと、モデルに送ったプロンプト、モデルの応答、システムプロンプト（全呼び出しで共通）を確認できます。設定ページを開いたまま AI を呼び出したときは、「最新のログを読み込む」で最新の記録を取り込めます。

プロンプトには欄のメタデータだけを入れます。そのためプロファイルの値、欄に入力された値、API キー、リクエストヘッダが記録に入ることはありません。

記録は 7 日間だけ保存し、期限を過ぎたものは自動で削除します。保存期間は変えられません。件数が 1,000 件を超えたとき、または記録の合計が大きくなりすぎたときは、古いものから削除します。合計の大きさは、ブラウザの保存サイズの課金単位と同じ UTF-8 のバイト数で数えます。「ログを削除」で、いつでもすべて削除できます。AI を使わない設定のときは、記録は増えません。

「TSV でダウンロード」は、新しい順の TSV ファイル `jushoai-audit-log-YYYY-MM-DD.tsv` を保存します。送った欄の内容と応答も含まれます。表計算ソフトで開いても数式が実行されないよう、`=` `+` `-` `@` で始まる値の先頭には `'` を付けます。ファイルにはページのアドレスや欄の内容が含まれるため、扱いは利用者の責任で行ってください。

## 端末内だけに保存・保持するデータ

AI の設定や監査ログ以外に、JushoAI が扱うデータのうち次のものは外部に送信せず、端末内だけに置かれます。

| データ | 保存・保持場所と内容 | 外部送信 |
|---|---|---|
| プロファイル・住所 | ブラウザ内ストレージ。登録した個人情報（エクスポート時のみ利用者操作で平文 JSON を書き出し） | なし |
| 覚えた対応付け | ブラウザ内ストレージ。ドメインと欄の特徴（`name` / `id`）→分類名のみ（最大 500 件）。プロファイル値なし | なし |
| 短縮プレビュー用の承認記録 | ブラウザ内ストレージ。承認内容のハッシュ値と選択 ID のみ（最大 100 サイト）。元の値やラベル文字列なし | なし |
| サイトごとのプロファイル候補 | ブラウザ内ストレージ。ホスト名→プロファイル ID のみ（最大 100 サイト）。プロファイル値なし | なし |
| 一時メモリ（`元に戻す`・`ゲストで入力`・複数ページ引継ぎ） | タブのメモリ内のみ。ストレージにも監査ログにも保存せず、タブを閉じると消去 | なし |

## API キーの保管

API キーは、AES-GCM で暗号化して保存します。鍵は取り出せない形で、別の保管場所（IndexedDB）に置きます。ストレージだけが流出しても、復号できません。ただし、拡張機能自身のコードからは読み出せます。

API キーは、設定ページにも表示しません。保存済みかどうかだけを表示し、置き換えと削除ができます。

## 通信の許可

通信の許可は、拡張機能のインストール時には求めません。設定ページで保存したときに、そのプロバイダのホストと検証用のリゾルバ（`dns.google`）だけを求めます（オプショナル権限）。許可はホスト単位でポートを区別しないため、同じホストの別のポートにも及びます。実際に送る先は、保存した接続先に限られます。許可しないと AI は使われません。Firefox では、このときホストの許可に加えて、ウェブサイトのコンテンツ（入力欄のメタデータ）をプロバイダに送ることへの同意（データ収集の権限）も求めます。

## 開発への報告（GitHub Issue）

問題や対応フォームを知らせる機能は、利用者が明示的にボタンを押したときだけ GitHub の新規 Issue 作成画面を開きます。いずれもプロファイルの値や欄に入力された値は送りません。

- **適用後の「内訳をissueで報告」**: 結果ごとの件数内訳（適用済み・入力済みスキップ・文字数超過など）と、最小化したページ URL（オリジン＋第 1 パスセグメント）、プロバイダ名、拡張バージョンだけを下書きに入れます。欄のメタデータや分類名は含みません。
- **再分析後の「開発に報告する」**: 最小化したページ URL、プロバイダ名、拡張バージョンに加え、初回と再分析の分類結果および欄のメタデータ（`name`・`htmlId`・`label`・`placeholder`・見出し、各 80 文字まで）を下書きに入れます。ページ上の文言に個人情報が書かれている場合は、Issue を投稿する前に削除してください。
- **設定画面の「不具合報告」**: 拡張バージョンと記入用のテンプレートだけを開きます。
