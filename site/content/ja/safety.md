# 安全のための仕組み

JushoAI は氏名や住所を扱います。そのため、勝手に入力しない、勝手に送らない、守りを何重にもする、を設計の前提にしています。ここでは、実際に行っていることを一覧にします。

## 入力するときの保護

- ボタンを押しても、すぐには入力しません。プレビューで欄と値を確認し、「入力する」を押したときだけ入力します。
- ページを開いただけで入力することはありません。
- 入力済みの欄は上書きしません。プレビューを開いている間に自分で入力した欄も上書きしません。
- 最大文字数を超える値は、切り詰めずに警告して入力しません。
- 欄の `pattern` 属性と合わない値は、無理に入力せず「欄のパターンと合わないため入力しません」と警告して飛ばします。極端に複雑な正規表現や長すぎるパターン・文字列は、ブラウザのタブが固まるのを防ぐため安全に検査を省略します。
- 建物名の略記候補（「略記して入れる」）や、カナ読み辞書・郵便番号辞書による入力補助候補（「補助候補を入れる」）は、プレビューでチェックを入れて承認したときだけ入力します。
- 読み取り専用（`readonly`）と無効（`disabled`）の欄は飛ばします。
- 郵便番号の欄は最後に入力します。住所を自動補完するフォームとの競合を避けるためです。
- 入力の途中でプレビューが消えた、画面の外に出た、隠れた、ほかの要素に覆われたときは、入力を中止します。

## 元に戻す

入力の直後は、結果画面の「元に戻す」で、JushoAI が入れた欄だけを入力前の空の状態に戻せます。あとから自分で書き足した欄は、内容が一致しないため触りません。

戻せるのは直近の入力だけです。履歴はページ（タブ）の中のメモリにだけ置き、保存も送信もせず、タブを閉じると消えます。

## 値は決まった処理で作る

AI は、入力欄が何の欄かを分類するだけです。入れる値は作りません。分割、カナ変換、半角・全角の調整、ハイフンの要否は、すべて決まった処理で行います。プロファイルの値は、AI にも外部にも渡しません。

AI は初期状態でオフです。ルールで判定できない欄の補助にだけ、設定したときに使います。

## 送る前の確認と最小送信

AI を有効にしているときでも、ルールで判定できない欄を外部に送る前に「AI判定で送る内容」の確認画面が開きます。

- 送られる欄のメタデータ（`name`・`id`・`label`・`placeholder`・見出し・`type`・`maxLength`）を事前に確認できます。
- 個人情報らしき文言を含む欄には「（要確認）」が付き、既定で「送らない」にチェックが入ります。
- プレビューの「直す」で意味を教えた欄（覚えた対応付け）は、自動的に除外され AI には送りません。
- 「ルールのみで入力する」を選ぶか、Esc キー等で閉じれば何も送らずルールだけで進みます。

プロファイルの値、欄に入っている値、選択肢は送りません。送る項目の一覧は [プライバシーと送信データ](./privacy.md) にあります。

通信は「JushoAI で入力」「AI で分析」を押したときと、設定ページで「接続テスト」を実行したときだけです。AI を呼び出すたびに、送った内容を端末内の監査ログに記録します。記録は設定ページで確認、ダウンロード、削除でき、7 日で自動的に消えます。

## 接続先の検証

クラウドの AI を使うとき、接続先は次の順で確かめます。

1. ベース URL は `https` のみです。`http` は `localhost` と `127.0.0.1` だけ使えます。URL に認証情報、クエリ、フラグメントを含めることはできません。
2. 内部ネットワークのアドレスは拒否します。NAT64 や 6to4 などの IPv6 変換プレフィックスを含む内部アドレスも拒否し、URL に直接 IPv6 アドレスを書くこともできません。
3. 保存するときにホスト名を名前解決し、内部アドレスに解決される、または解決を確認できないときは保存を拒否します。呼び出しの直前にも、もう一度確かめます。
4. HTTP のリダイレクトは辿りません。別のホストへ転送されても、そこへは送りません。
5. 初めて使う接続先は、IP アドレスの一覧を見て「この接続先を承認する」で承認するまで、何も送りません。

検証と実際の接続は別々の名前解決のため、その間に解決結果が変わる攻撃（DNS rebinding）を完全には排除できません。この点は [プライバシーと送信データ](./privacy.md) にも書いています。

## API キーと権限

API キーは AES-GCM で暗号化して保存します。鍵は取り出せない形で、別の保管場所（IndexedDB）に置きます。設定ページにはキーを表示せず、保存済みかどうかだけを表示します。接続先のオリジンを変えると、保存済みのキーは破棄します。

通信の許可は、インストール時には求めません。設定ページで保存したときに、そのプロバイダのホスト（および名前解決の確認に使う `dns.google`）だけを求めます。許可しない限り、AI は使われません（Firefox ではウェブサイトのコンテンツ送信への同意もあわせて求めます）。

## タブの中だけに置く一時データ

次の 3 つのデータは、開いているタブのメモリの中にだけ置き、拡張機能のストレージや監査ログに保存しません。エクスポートにも含まれず、外部へ送信もせず、タブを閉じると消えます。

- **「元に戻す」の履歴**: 直前に入力した欄と値の対応だけを持ち、ページから移動またはタブを閉じると消えます。
- **「ゲストで入力」の値**: 保存しない使い捨ての入力用データです。1 回の入力が終わるかタブを閉じると消えます。
- **複数ページ引継ぎの値**: 複数ステップに分かれた申込フォームで、前のページで入力した値を同じタブ内の次のページ候補に引き継ぎます。タブを閉じると消えます。

## 画面の分離

JushoAI の画面は、閉じた Shadow DOM の中に置きます。ページ側のスクリプトからは操作できません。ページ由来の文字列（ラベルなど）は、HTML として解釈せず、文字としてだけ表示します。

## 対象外にしていること

- 別のオリジンの iframe の中にあるフォームには入力しません。
- チェックボックス、hidden、送信ボタン、複数行テキスト（`textarea`）、性別と年代以外のラジオボタンは対象にしません。
- 起動しない URL を登録したページでは、動きません。登録は [フォームへの入力とツールバー](./popup-and-fill.md) を参照してください。

脆弱性を見つけたときは、公開の Issue ではなく GitHub の非公開報告から送ってください。手順と対応の目安は [セキュリティポリシー](https://github.com/armaniacs/jushoai/security/policy) にあります。
