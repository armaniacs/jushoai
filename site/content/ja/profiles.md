# プロファイル

プロファイルは、入力に使う「人」の情報です。本人用、家族用のように、最大 10 件まで登録できます。登録した値は、このブラウザの中だけに保存します。

## 登録する

拡張機能の設定ページを開き、左メニューの「プロファイル」を選びます。

| 項目 | 備考 |
|---|---|
| 名前 | プロファイルの呼び名です。「本人」「家族」など、選ぶときの目印になります。 |
| 姓・名 | |
| セイ・メイ | 全角カナです。ひらがなや半角で入れても、保存時に全角カナへ直ります。 |
| ローマ字の姓・名 | ローマ字の欄があるフォーム用です。任意です。 |
| 生年月日 | 年・月・日や元号に分かれた欄にも入れられます。任意です。 |
| 学校名・学部・学科 | 任意です。 |
| メールアドレス | |
| 電話番号 | 10〜11 桁の数字です。ハイフンは取り除かれます。 |
| 性別 | 性別の選択欄やラジオボタン用です。任意です。 |

## 複数のプロファイルを使い分ける

- 追加: 「プロファイルを追加」で増やします。10 件に達すると、追加できません。
- 複製: 既存のプロファイルをコピーして、違う項目だけ直せます。
- 削除: 不要なプロファイルを削除します。

フォームで「JushoAI で入力」を押すと、プレビューの上部で、使うプロファイルを選べます。選び直すと、一覧が更新されます。

## 住所との関係

住所は、使うプロファイルに紐付けられます。プロファイルを切り替えると、紐付けた住所が自動で選ばれます。詳しくは [住所](/guides/addresses/) を参照してください。
