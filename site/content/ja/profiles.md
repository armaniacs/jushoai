# プロファイル

プロファイルは、入力に使う「人」の情報です。本人用、家族用、子ども用のように、最大 10 件まで登録できます。登録した値は、このブラウザの中だけに保存します。

自分の情報を入れる前に試したいときは、設定ページ上部の案内から「架空の名前を作って試す」（住所も未登録のときは「架空の名前と住所を作って試す」）で、架空のサンプルデータを作って動作を確認できます。

## 登録する

拡張機能の設定ページを開き、左メニューの「プロファイル」を選びます。入力後、「保存」を押すとプロファイルだけを保存できます（住所をまだ入力していなくても保存でき、その場合は「住所を入力する」の案内が出ます）。

| 項目 | 備考 |
|---|---|
| 名前（個人用・家族用など） | プロファイルの呼び名です。「個人用」「家族」など、選ぶときの目印になります（必須）。 |
| 姓・名 | 氏名です（必須）。 |
| セイ（フリガナ・ふりがな入力可）・メイ（フリガナ・ふりがな入力可） | 全角カナです（必須）。ひらがなや半角で入力しても、保存時に全角カナへ変換されます。入力中は下にひらがな表示のプレビューが出ます。 |
| 姓（ローマ字・半角英字・任意）・名（ローマ字・半角英字・任意） | ローマ字の欄があるフォーム用です（任意）。1 欄のローマ字欄では「名 姓」の順で入ります。 |
| 生年月日 | 任意。`1990-05-07`（`YYYY-MM-DD`）形式で入力します（`1990/5/7` や `1990年5月7日` も保存時に整形されます）。年・月・日、元号、1 欄型（`type=date` を含む）、年代（プルダウン・ラジオボタン）に対応します。 |
| 性別（任意） | 任意。「男性」「女性」「その他」「回答しない」から選びます。性別の選択欄やラジオボタン（英語の Male / Female を含む）用です。 |
| `学校名`・`学部・学科`・`学校の学年`・`塾名` | いずれも任意。学校や塾の申込フォームで使われます。 |
| 会社名（任意）・会社名（フリガナ・任意）・会社の部署（任意）・役職（任意） | いずれも任意。勤務先や法人向けフォームで使われます。 |
| メールアドレス | 任意。入力する場合はメールアドレス形式を確認します。 |
| 電話番号 | 任意。10〜11 桁の数字です（ハイフンは保存時に取り除かれます）。通常の電話番号欄のほか、FAX 番号欄や、電話の語を含まない 3 分割の緊急連絡先欄にも使われます。 |

開いているフォームに入力済みの内容を取り込んで下書きを作りたいときは、「フォームから取り込む」も使えます（[1 欄入力・取り込み・移行と管理](./shortcuts-and-tools.md)）。

## 複数のプロファイルを使い分ける

- **追加**: 「プロファイルを新規追加」で増やします。10 件に達すると追加できません。
- **複製**: 「このプロファイルを複製」で既存のプロファイルをコピーし、違う項目だけ直せます（10 件に達しているときは使えません）。
- **削除**: 「このプロファイルを削除」で不要なプロファイルを削除できます。最後の 1 件も削除できます（ただし 0 件のままでは保存できません）。

複数のプロファイルを登録している場合、フォームで「JushoAI で入力」を押すと、プレビューの上部で使うプロファイルを選べます。選び直すと、一覧が即座に更新されます。

- **サイトごとの候補提示**: あるサイトで入力すると、そのサイト（ホスト名）で使ったプロファイルの ID を端末内だけに記憶します（最大 100 サイト）。次回同じサイトを開いたときは、そのプロファイルがプレビューの最初の候補として選ばれます（確認なしに自動入力されることはなく、いつでも切り替えられます）。
- **児童用・保護者用の使い分け**: 学校や塾の申込フォームなど、1 つの画面に児童向けと保護者向けの欄が両方あるときは、2 件以上のプロファイルを登録していればプレビューに「児童用」「保護者用」の 2 つの選択欄が出ます（[シーン別の使いこなし](./scenarios.md)）。
- **保存せず 1 回だけ使いたいとき**: 上限 10 件を増やさずに家族や友人の分を 1 回だけ入力したいときは、ツールバーの「ゲストで入力」が使えます（[シーン別の使いこなし](./scenarios.md)）。

## 住所との関係

住所は、使うプロファイルに紐付けられます。プロファイルを切り替えると、紐付けた住所（または共通の住所）が自動で選ばれます。詳しくは [住所](./addresses.md) を参照してください。
