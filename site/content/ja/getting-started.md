# はじめに

JushoAI は、氏名・住所などの入力欄が並ぶフォームに、登録した情報を入力する Chromium 系ブラウザと Firefox 128 以上向けの拡張機能です。Edge は Edge アドオンで、Firefox は Firefox アドオン（AMO）で公開しています。Firefox（128 以上）では、フォームへの入力の流れを自動テストで確認しています（クラウド AI の通信は未確認です）。本拡張は日本語ユーザーのための拡張であり、画面表示は日本語専用としています（意図的な仕様であり、英語表示には対応していません）。

## インストール

Chrome は Chrome ウェブストアから、Edge は Edge アドオンから、Firefox は Firefox アドオン（AMO）からインストールできます。

[Chrome ウェブストアで JushoAI を開く](https://chromewebstore.google.com/detail/jushoai/ijlccdbapahelcgpcopgkhdjhkkicbpl?hl=ja)

[Edge アドオンで JushoAI を開く](https://microsoftedge.microsoft.com/addons/detail/jushoai/oobgmceceepjapoplehjkkbbpabbddhi?hl=ja)

[Firefox アドオンで JushoAI を開く](https://addons.mozilla.org/ja/firefox/addon/jushoai/)

Firefox に zip を読み込む場合は、[GitHub Releases](https://github.com/armaniacs/jushoai/releases) の `jushoai-<バージョン>-firefox.zip` を展開してから `about:debugging#/runtime/this-firefox` を開き、「一時的なアドオンを読み込む」で展開したフォルダ内の `manifest.json` を選びます。一時的なアドオンは Firefox を終了すると外れ、登録したプロファイル・住所と暗号化キーも一緒に失われます。使うたびに読み込み直して、登録し直します。

Chrome や Edge で zip から読み込む場合は、[GitHub Releases](https://github.com/armaniacs/jushoai/releases) の zip を展開し、次の手順で読み込みます。

1. 「デベロッパーモード」を有効にします（Chrome は `chrome://extensions`、Edge は `edge://extensions`）。
2. 「パッケージ化されていない拡張機能を読み込む」を選びます。ボタンの表記はブラウザや言語によって異なることがあります。
3. 展開したフォルダを選びます。

## プロファイルと住所を登録する

拡張機能の設定ページを開き、次の項目を入力します。

| 区分 | 項目 | 備考 |
|---|---|---|
| プロファイル | 姓・名 | |
| プロファイル | セイ・メイ | 全角カナです。ひらがなや半角で入れても、保存時に全角カナへ直ります。 |
| プロファイル | メールアドレス | |
| プロファイル | 電話番号 | 10〜11 桁の数字です。ハイフンは取り除かれます。 |
| 住所 | 名前 | 自宅、勤務先などです。 |
| 住所 | 郵便番号 | 7 桁です。 |
| 住所 | 都道府県 | 一覧から選びます。 |
| 住所 | 市区町村 | |
| 住所 | 番地 | |
| 住所 | 建物名 | 任意です。 |

住所は複数登録できます（それぞれ 10 件まで）。

設定ページの「フォームから取り込む」で、開いているフォームの値から下書きを作れます。プロファイルと住所はファイルに書き出して、別の環境へ取り込めます。書き出したファイルは平文です。Firefox の一時的なアドオンは終了時に登録内容が消えるため、書き出しておくと再登録が楽です。詳しくは [便利な使い方](/guides/shortcuts-and-tools/) を参照してください。

プロファイルと住所（1 件以上）を登録していないと、「JushoAI で入力」を押したときに設定ページが開きます。

## AI を使う場合（任意）

AI は必須ではありません。ルールで判定できない欄の分類にだけ使います。使うには、設定ページの「AI 判定」で次の順に進みます。

1. 「AI プロバイダ」で使う種類を選びます（ブラウザ内蔵 AI、OpenAI 互換 API、Google Gemini）。
2. OpenAI 互換 API の場合は、ベース URL・モデル名・API キーを入力して保存します。保存時に、そのプロバイダへの通信の許可をブラウザが確認します。
3. 保存した接続先に初めて送信する前には、接続先の承認が必要です。保存済みの接続先の下に表示される IP アドレスの一覧（ホスト名を DNS で解決した結果）が想定どおりか確かめてから、「この接続先を承認する」を押します。承認するまで、その接続先には何も送信しません。
4. 「接続テスト」で動作を確かめます。

詳しくは [AI プロバイダの設定](/guides/ai-providers/) を参照してください。

## フォームで使う

氏名や住所などの入力欄が複数あるフォームの近くに、「JushoAI で入力」ボタンが出ます。

ボタンが出るのは、text・email・tel・search の入力欄と select が合わせて 3 つ以上あるフォームです。そのうち 2 つ以上を判定できる場合に限ります。

1. 「JushoAI で入力」を押します。プレビューが開き、欄と値の一覧が出ます。
2. 入力済みの欄、文字数を超える欄、選択肢がない欄には、注記が付きます。
3. AI が分類した欄には「AI判定」の印が付きます。
4. 「入力する」を押すと、プレビューで注記が付いていない欄にだけ入力します。

Esc キーか「キャンセル」で閉じます。プレビューを開いている間に自分で入力した欄は、上書きしません。郵便番号の欄は最後に入力します。住所を自動補完するフォームとの競合を避けるためです。

## 安全のために

JushoAI は、次の約束で動きます。

- プレビューで確認して「入力する」を押すまで、何も入力しません。ページを開いただけで入力することはありません。
- 入力済みの欄は上書きせず、最大文字数を超える値は切り詰めずに警告します。
- 入力した直後は、プレビューの「元に戻す」で、JushoAI が入れた欄だけを戻せます。
- AI は初期状態でオフです。使う設定にしても、送るのは欄のメタデータだけで、プロファイルの値は送りません。
- 初めて使う AI の接続先は、承認するまで何も送りません。

仕組みの全体は [安全のための仕組み](/guides/safety/) にあります。
