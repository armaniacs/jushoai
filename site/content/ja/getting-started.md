# はじめに

JushoAI は、氏名・フリガナ・住所などの入力欄が並ぶ日本の Web フォームに、登録した情報を安全に入力する Chromium 系ブラウザと Firefox（128 以上）向けの拡張機能です。Chrome ウェブストア、Edge アドオン、Firefox アドオン（AMO）で公開しています。Firefox（128 以上）では、フォームへの入力の流れを自動テストで確認しています（クラウド AI の通信は未確認です）。本拡張は日本語ユーザーのための拡張であり、画面表示は日本語専用としています（意図的な仕様であり、英語表示には対応していません）。

## インストール

Chrome は Chrome ウェブストアから、Edge は Edge アドオンから、Firefox は Firefox アドオン（AMO）からインストールできます。

[Chrome ウェブストアで JushoAI を開く](https://chromewebstore.google.com/detail/jushoai/ijlccdbapahelcgpcopgkhdjhkkicbpl?hl=ja)

[Edge アドオンで JushoAI を開く](https://microsoftedge.microsoft.com/addons/detail/jushoai/oobgmceceepjapoplehjkkbbpabbddhi?hl=ja)

[Firefox アドオンで JushoAI を開く](https://addons.mozilla.org/ja/firefox/addon/jushoai/)

Firefox に zip を読み込む場合は、[GitHub Releases](https://github.com/armaniacs/jushoai/releases) の `jushoai-<バージョン>-firefox.zip` を展開してから `about:debugging#/runtime/this-firefox` を開き、「一時的なアドオンを読み込む」で展開したフォルダ内の `manifest.json` を選びます。一時的なアドオンは Firefox を終了すると外れ、登録したプロファイル・住所と暗号化キーも一緒に失われます。使うたびに読み込み直して、登録し直します。

Chrome や Edge で zip から読み込む場合は、[GitHub Releases](https://github.com/armaniacs/jushoai/releases) の zip を展開し、次の手順で読み込みます。

1. 「デベロッパーモード」を有効にします（Chrome は `chrome://extensions`、Edge は `edge://extensions`）。
2. 「パッケージ化されていない拡張機能を読み込む」を選びます。ボタンの表記はブラウザや言語によって異なることがあります。
3. 展開したフォルダを選びます。

## お試しと登録（プロファイル・住所）

拡張機能の設定ページを開くと、初回（プロファイルと住所がまだ登録されていないとき）は上部に「初めてですか？架空の名前と住所で試せます」という案内が出ます。本物の個人情報を入力する前に動作を試したいときは、「架空の名前と住所を作って試す」（片方だけ未登録のときは「架空の名前を作って試す」または「架空の住所を作って試す」）を押すだけで、架空のサンプルデータが作られてすぐにフォームで試せます。

自分の情報を登録する場合は、左メニューの「プロファイル」と「住所」で次の主要項目を入力し、それぞれの画面の「保存」を押します（最大各 10 件まで登録でき、登録した値はブラウザ内だけに保存します）。

| 区分 | 項目 | 備考 |
|---|---|---|
| プロファイル | 名前 | 本人、家族、子どもなどの呼び名です。 |
| プロファイル | 姓・名 | |
| プロファイル | セイ・メイ | 全角カナです。ひらがなや半角で入れても、保存時に全角カナへ直ります。 |
| プロファイル | メールアドレス | |
| プロファイル | 電話番号 | 10〜11 桁の数字です。ハイフンは取り除かれます。 |
| 住所 | 名前 | 自宅、勤務先などの呼び名です。 |
| 住所 | 郵便番号 | 7 桁の数字です。 |
| 住所 | 都道府県 | 一覧から選びます。 |
| 住所 | 市区町村 | |
| 住所 | 番地 | |
| 住所 | 建物名・部屋番号 | 任意です。 |

このほか、ローマ字の姓名、生年月日、性別、学校・塾、会社・部署・役職、英語住所などの任意項目にも対応しています。全項目の仕様は [プロファイル](./profiles.md) と [住所](./addresses.md) を参照してください。

「プロファイル」タブと「住所」タブはそれぞれ別々に保存できます。片方だけを先に保存すると、もう片方の入力を促す案内（「住所を入力する」または「プロファイルを入力する」）が表示されます。

設定ページの「フォームから取り込む」で、開いているフォームの値から下書きを作ることもできます。また、プロファイルと住所は JSON ファイルに書き出して別の環境へ取り込めます（平文で書き出されるため取り扱いにご注意ください。Firefox の一時的なアドオンでは再登録に便利です）。詳しくは [1 欄入力・取り込み・移行と管理](./shortcuts-and-tools.md) を参照してください。

プロファイルと住所（各 1 件以上）を登録していない状態で「JushoAI で入力」を押すと、設定ページが開きます。

## フォームで使う

`text`・`email`・`tel`・`search`・`date` の入力欄と `select`（プルダウン）、ラジオボタングループ（性別・年代に対応）が合わせて 3 つ以上あり、そのうち 2 つ以上を判定できるフォームの近くに、「JushoAI で入力」ボタンが出ます。

1. 「JushoAI で入力」を押します（AI を有効にしていてルールで判定できない欄がある場合は、送信前に「AI判定で送る内容」の確認画面が開きます）。
2. プレビュー（「入力内容の確認」）が開き、先頭に対応状況（`x / y 欄に入力できます（承認後に注入します）`）と、欄と値の一覧が出ます。
3. 入力済みの欄、文字数を超える欄、パターンと合わない欄、選択肢がない欄、値が未登録の欄には注記が付きます（建物名の略記候補や未登録時の補助候補が出ることもあります）。
4. AI が分類した欄には「AI判定」の印が付きます。
5. 児童向け・保護者向けの欄が両方あるフォームでプロファイルを 2 件以上登録しているときは、プレビュー上部の「児童用」「保護者用」から別々のプロファイルを選んでまとめて入力できます（[シーン別の使いこなし](./scenarios.md)）。
6. 「入力する」を押すと、プレビューで注記が付いていない欄（およびチェックを入れた補助候補）にだけ入力します。
7. 入力後は結果画面（「入力結果」）に切り替わり、直後であれば「元に戻す」で JushoAI が入れた欄だけを元の空状態に戻せます。

入力せずに閉じたいときは Esc キーか「キャンセル」を押します。プレビューを開いている間に自分で入力した欄は上書きしません。また、郵便番号の欄は最後に入力します（住所を自動補完するフォームとの競合を避けるためです）。

## AI を使う場合（任意）

AI は必須ではありません。初期状態はオフで、ルールで判定できない欄の分類にだけ使います。使う場合は、設定ページの「AI 判定（任意）」で次の順に進みます。

1. 「AI プロバイダ」で使う種類を選びます（ブラウザ内蔵 AI、OpenAI 互換 API、Google Gemini）。
2. 必要な項目（OpenAI 互換 API の場合はベース URL・モデル名・API キーなど）を入力して「保存」を押します。保存時に、そのプロバイダへの通信の許可をブラウザが確認します（Firefox ではデータ送信への同意も確認します）。
3. OpenAI 互換 API で保存した接続先に初めて送信する前には、設定ページで接続先の承認が必要です。ホスト名を DNS で解決した IP アドレスの一覧が想定どおりか確かめてから、「この接続先を承認する」を押します。承認するまで、その接続先には何も送信しません。
4. 「接続テスト（保存済みの設定で実行）」で動作を確かめます。
5. フォームで AI を使うときは、送信前に毎回「AI判定で送る内容」の確認パネルが開き、実際に送られる欄のメタデータを確認・除外してから送信できます。

詳しくは [AI プロバイダの設定](./ai-providers.md) を参照してください。

## 安全のために

JushoAI は、次の約束で動きます。

- プレビューで確認して「入力する」を押すまで、何も入力しません。ページを開いただけで入力することはありません。
- 入力済みの欄は上書きせず、最大文字数を超える値は切り詰めずに警告します。
- 入力した直後は、結果画面の「元に戻す」で、JushoAI が入れた欄だけを戻せます。
- AI は初期状態でオフです。使う設定にしても、送るのは欄のメタデータだけで、プロファイルの値は送りません。送信前にも「AI判定で送る内容」で確認できます。
- 初めて使う OpenAI 互換 API の接続先は、IP アドレスを確認して承認するまで何も送りません。

仕組みの全体は [安全のための仕組み](./safety.md) にあります。

## 複数のプロファイル・住所がある場合

プレビューの上部で、使うプロファイルと住所を選べます。選び直すと、一覧が即座に更新されます。一度入力したサイトでは次回そのプロファイルが優先候補として選ばれ、同じフォームを再訪したときは変更点だけを短い表示で確認できます。
