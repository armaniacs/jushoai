# はじめに

JushoAI は、氏名・住所などの入力欄が並ぶフォームに、登録した情報を入力する Chromium 系ブラウザと Firefox 128 以上向けの拡張機能です。Edge で動作を確認しています。Firefox（128 以上）は、フォームへの入力の流れを自動テストで確認しています（クラウド AI の通信は未確認です）。

## インストール

ストアには公開していません。GitHub Releases の zip を使います。

[GitHub Releases](https://github.com/armaniacs/jushoai/releases) から zip をダウンロードして、展開します。

次に、ブラウザの拡張機能ページを開きます。Chrome は `chrome://extensions`、Edge は `edge://extensions` です。Firefox は `about:debugging#/runtime/this-firefox` を開き、「一時的なアドオンを読み込む」で `firefox-mv3` フォルダ内の `manifest.json` を選びます（Firefox を再起動すると外れます）。

1. 「デベロッパーモード」を有効にします。
2. 「パッケージ化されていない拡張機能を読み込む」を選びます。ボタンの表記はブラウザや言語によって異なることがあります。
3. 展開したフォルダを選びます。

## プロファイルと住所を登録する

拡張機能の設定ページを開き、次の項目を入力します。

| 区分 | 項目 | 備考 |
|---|---|---|
| プロファイル | 姓・名 | |
| プロファイル | セイ・メイ | 全角カナです。ひらがなや半角で入れても、保存時に全角カナへ直ります。 |
| プロファイル | メールアドレス | |
| プロファイル | 電話番号 | 10〜11 桁の数字です。ハイフンは取り除かれます。 |
| 住所 | 名前 | 自宅、勤務先などです。 |
| 住所 | 郵便番号 | 7 桁です。 |
| 住所 | 都道府県 | 一覧から選びます。 |
| 住所 | 市区町村 | |
| 住所 | 番地 | |
| 住所 | 建物名 | 任意です。 |

住所は複数登録できます。

プロファイルと住所（1 件以上）を登録していないと、「JushoAI で入力」を押したときに設定ページが開きます。

## フォームで使う

氏名や住所などの入力欄が複数あるフォームの近くに、「JushoAI で入力」ボタンが出ます。

ボタンが出るのは、text・email・tel・search の入力欄と select が合わせて 3 つ以上あるフォームです。そのうち 2 つ以上を判定できる場合に限ります。

1. 「JushoAI で入力」を押します。プレビューが開き、欄と値の一覧が出ます。
2. 入力済みの欄、文字数を超える欄、選択肢がない欄には、注記が付きます。
3. AI が分類した欄には「AI判定」の印が付きます。
4. 「入力する」を押すと、プレビューで注記が付いていない欄にだけ入力します。

Esc キーか「キャンセル」で閉じます。プレビューを開いている間に自分で入力した欄は、上書きしません。郵便番号の欄は最後に入力します。住所を自動補完するフォームとの競合を避けるためです。

## 住所を複数登録している場合

プレビューの上部で、使う住所を選べます。選び直すと、一覧が更新されます。
