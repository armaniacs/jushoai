# トラブルシューティング

## バッジの状態と対処

バッジを押すと、状態に応じた案内が開きます。設定が必要な状態では、「AI 設定を開く」ボタンがあります。

| バッジ | 状態 | 対処 |
|---|---|---|
| AI: オフ | プロバイダが「使わない」です。 | 使う場合は、設定ページでプロバイダを選びます。 |
| AI 未設定 | 設定が不足しています（ベース URL、モデル名、API キーなど）。保存済みの API キーが復号できない場合も、この表示です。 | 設定ページで入力し直します。 |
| AI 権限なし | 通信の許可がありません。 | 設定ページで保存し直し、許可します。 |
| AI 認証エラー | プロバイダが認証を拒否しました。 | API キーを確認します。Ollama などローカルの場合は、`OLLAMA_ORIGINS` を確認します。 |
| AI: OpenAI 互換 / AI: Gemini | 利用できます。 | 不要です。 |
| AI 有効 | ブラウザ内蔵 AI が利用できます。 | 不要です。 |
| AI 未準備 | 内蔵 AI のモデルが未ダウンロードです。 | 「JushoAI で入力」を押すと、ダウンロードを試みます。 |
| AI 準備中 | 内蔵 AI のモデルをダウンロード中です。 | 完了を待ちます。 |
| AI 無効 | 内蔵 AI が使えません（フラグ、端末の条件、Firefox など非対応のブラウザ）。鍵の保存の一時的な失敗でもこの表示になります。 | バッジを押して案内を見ます。フラグを確認します。一時的な失敗のときは、時間をおいて試すと直ります。 |

## AI がうまく動かないとき

まず、設定ページで「接続テスト（保存済みの設定で実行）」を試します。保存してから実行してください（連打防止のため、実行後約 3 秒間はボタンが無効になります）。

- **認証に失敗する**: API キーを確認します。
- **Ollama で 403 になる**: Ollama 側の `OLLAMA_ORIGINS` に、`chrome-extension://<拡張機能の ID>`（Firefox は設定ページに表示される `moz-extension://<UUID>`。UUID はインストールごとに変わる）を許可します。
- **拒否される**: モデル名と、モデルが JSON 形式の出力に対応しているかを確認します。
- **接続に失敗する**: URL、モデル名、ネットワークを確認します。
- **通信が許可されていない**: 設定ページで保存し直し、許可します。
- **ブラウザ内蔵 AI が無効**: Chrome / Edge のフラグを有効にして再起動します（Firefox は非対応です）。設定は [AI プロバイダの設定](./ai-providers.md) にあります。

## 入力されない、おかしいとき

- **「JushoAI で入力」が出ない**: `text`・`email`・`tel`・`search`・`date` の入力欄と `select` とラジオボタングループが合わせて 3 つ以上あり、そのうち 2 つ以上を判定できるフォームにだけ出ます。非表示の欄は数えません。
- **設定ページが開く**: プロファイルと住所（1 件以上）が未登録です。
- **欄に入力されない**: プレビューで注記が付いていない欄にだけ入力します。入力済み、文字数超過、`pattern` 不一致、選択肢なし、値未登録の欄には注記が付きます。`readonly` と `disabled` の欄は飛ばします。また、塾の検索補助窓（見た目だけ埋まるのを防ぐため意図的に未入力）や、前の選択後に選択肢が現れる連動プルダウンも対象外や未入力になります。
- **対応していない欄がある**: `type=date` の生年月日欄には対応しています。チェックボックス、ファイル、複数行テキスト（`textarea`）、性別・年代以外のラジオボタンは対象外です。判定できない欄には入力しません。
- **郵便番号が最後に入る**: 住所を自動補完するフォームとの競合を避けるためです。

判定の詳細は [対応するフォームと仕組み](./how-it-works.md) を参照してください。

## よくある質問

### AI を使わなくても動きますか

動きます。欄の判定はルールで行います。AI は、ルールで判定できない欄の分類だけに使います。AI を設定しない限り、外部への通信はありません。

### 何が送られますか

ブラウザ内蔵 AI 以外の AI プロバイダを設定した場合だけ、ルールで判定できない欄のメタ情報を送ります。内訳は欄を区別するための内部 ID、`name`、`htmlId`、`label`、`placeholder`、見出し、`type`、`maxLength` です。プロファイルの値は送りません。ラベルや見出しはページ上の文言なので、表示されている個人情報が含まれることがあります。送信前に「AI判定で送る内容」画面で内容を確認できます。詳しくは [プライバシーと送信データ](./privacy.md) を参照してください。

### 送信前の確認画面で「（要確認）」が付く欄があります

ラベルや見出し、placeholder などに、ページに書かれた氏名・住所・電話番号・郵便番号・メールアドレスらしい文字列が含まれているためです。意図せず外部へ送らないよう、既定で「送らない」にチェックが入っています。送ってよいと確認できた場合だけチェックを外してください。

### 誤入力が心配です

入力前にプレビューで、欄と値を確認できます。入力するのは、プレビューで注記が付いていない欄だけです。入力済みの欄は上書きせず、最大文字数を超える値や `pattern` と合わない値は入力しません。入力直後なら「元に戻す」で戻せます。

### どのフォームで使えますか

対象は `text`・`email`・`tel`・`search`・`date` の入力欄、`select`、性別・年代のラジオボタングループです。合わせて 3 つ以上あり、そのうち 2 つ以上を判定できるフォームで使えます。対応する欄の一覧は [対応する入力欄](./supported-fields.md) にあります。

### Ollama で 403 になります

Ollama は、`OLLAMA_ORIGINS` で許可していない限り、拡張機能のオリジンからの要求を 403 で拒否することがあります。`OLLAMA_ORIGINS` に `chrome-extension://<拡張機能の ID>` を許可してください。Firefox では、設定ページに表示される `moz-extension://<UUID>` を許可します。UUID はインストールごとに変わります。

### プレビューでは何を確認しますか

欄と値の一覧です。上部で使うプロファイルと住所を選べます。AI が分類した欄には「AI判定」の印が付きます。分類が違う欄は「直す」で修正できます。注記が付いた欄には入力しません。Esc キーか「キャンセル」で閉じます。

### 「前回と同じ」と折りたたまれた欄を全部見たい

同じサイト・同じ欄構成の再訪では、前回承認した内容から変わっていない行が「前回と同じ」に折りたたまれます。すべての行を確認したいときは、プレビュー下部の「前回と同じ欄を表示」を押すと一覧がすべて開きます。

### 児童用・保護者用の選択欄が出ません

「児童用」「保護者用」の選択欄は、フォーム内に児童と保護者の両方の入力欄があり、かつプロファイルが 2 件以上登録されているときだけ表示されます。プロファイルが 1 件だけの場合や、どちらか片方の役割だけのフォームでは、通常の 1 つの選択欄になります。

### 入力が始まらない／同意確認ではじかれる場合

プレビューの「入力する」を押しても何も入力されず、フォーム横のボタンに「パネルが…のため入力を中止しました」と出ることがあります。押した瞬間に、プレビューのパネルがページから取り除かれた、画面の外にある、表示されていない、他の要素に覆われている、のいずれかと判断したためで、安全のために注入の前に中止しています。中途半端に入力が残ることはありません。

パネルは開いたままなので、パネルが画面に収まり、他の要素に覆われていない状態に戻してから「入力する」を押し直してください。スクロールやズーム、重なったウィンドウや他の拡張機能の表示をどけると直ることがあります。

### 「元に戻す」を押しても戻らない欄があります

「元に戻す」が戻すのは、JushoAI が入力したときの値のままで残っている欄だけです。入力したあとに自分で文字を書き足したり書き換えたりした欄は、手入力の内容を壊さないよう保護のため触りません。

### 「AI で分析」は何をしますか

全ての欄を、設定した AI で分類し直します。ルールで判定できなかった欄を救うための機能です。分析後に「入力する」を押す承認は、別途必要です。

### ツールバーのアイコンを押すと何が見えますか

登録したプロファイルと住所の一覧と、使用中の表示です。「AI で分析」を押すと開いているタブのフォームで分類からプレビューまでを始め、「ゲストで入力」を押すと保存しない使い捨ての入力画面を開きます。右上の歯車で設定ページを開けます。

### 「ゲストで入力」した内容が次回残りません

「ゲストで入力」はストレージや監査ログに一切保存しない 1 回限りの使い捨て機能です。入力した内容はタブ内のメモリだけに置かれ、その 1 回の入力が終わるかタブを閉じると消えます。次回以降も使いたい情報は、設定ページの「プロファイル」「住所」に登録してください。

### 接続テストは何をしますか

保存済みの設定で、合成した 1 欄を分類させます。先に保存してから実行してください。接続テストの呼び出しも、監査ログに記録します。

### プロファイルは何件まで登録できますか

最大 10 件です。10 件に達すると、追加も複製もできません。削除すると減らせます。

### 住所は何件まで登録できますか

最大 10 件です。10 件に達すると、追加できません。

### 複数のプロファイルや住所はどう使い分けますか

プレビューの上部で、使うプロファイルと住所を選びます。住所にプロファイルを紐付けていると、プロファイルの切り替えに合わせて住所が自動で選ばれます。

### プロファイルや住所を登録しないとどうなりますか

「JushoAI で入力」を押すと、設定ページが開きます。先にプロファイルと住所を 1 件以上登録してください（1 回限りの場合はツールバーの「ゲストで入力」も使えます）。

### フリガナはひらがな・半角カナの欄にも入りますか

入ります。欄の例示や説明に合わせて、全角カタカナ、ひらがな、半角カナに変換します。

### ローマ字の欄には入りますか

プロファイルにローマ字の姓・名を登録している場合に、入ります。

### 住所が 1 つの欄しかありません

都道府県から建物名までを組み立てて、1 つの欄に入れます。建物名は、番地の後ろに半角スペースで続けます。

### 都道府県が数字のプルダウンです

「東京」「東京都」のような表記ゆれと、数字のコードの値も照合します。一致する選択肢がない場合は、注記を付けて入力しません。

### 電話番号が 3 つに分かれています

桁数で市外局番などに分けて入れます。ハイフンを入れるかどうかは、欄の例示と最大文字数から決めます。

### 郵便番号のハイフンはどうなりますか

欄の例示と最大文字数から決めます。7 桁の数字は、前半 3 桁と後半 4 桁に分けて入れられます。

### 年代の欄には何が入りますか

プロファイルの生年月日から求めた年代を入れます。プルダウンと、年代のラジオボタングループに対応します。

### 元号の欄には何が入りますか

プロファイルの生年月日から求めた元号を入れます。

### 入力済みの欄はどうなりますか

上書きしません。プレビューに「入力済みのため上書きしません」と注記が付きます。プレビューを開いている間に自分で入力した欄も、上書きしません。

### 長すぎる値は切り詰めますか

切り詰めません。最大文字数を超える値は、警告の注記を付けて入力しません。建物名を含む住所では、プレビューで「略記して入れる」にチェックを入れた場合だけ略記で入力できます。

### チェックボックスや日付の欄は

チェックボックス、ファイル入力、複数行テキスト（`textarea`）は対象外です。`type=date` の生年月日欄には対応しており、登録した生年月日を `YYYY-MM-DD` 形式で入力します。

### 性別以外のラジオボタンは

対象外です。ラジオボタンは、性別と年代のグループだけ対応します。

### 複数行の欄には入りますか

対象外です。複数行の欄（`textarea`）には入力しません。

### 登録したデータはどこに保存されますか

このブラウザの中だけです。外部に送信しません。

### API キーは安全に保存されますか

AES-GCM で暗号化して保存します。設定ページにも表示しません。保存済みかどうかだけを表示し、置き換えと削除ができます。

### 通信ログはどこで確認できますか

設定ページの「通信の監査ログ」で、一覧の確認、ダウンロード、削除ができます。日時・プロバイダ・宛先・モデル・ページの URL・送った欄の数・結果に加えて、モデルに送ったプロンプトとモデルの応答が 7 日間残ります。プロファイルの値は記録しません。

### ページを開いただけで通信しますか

しません。通信は、「JushoAI で入力」「AI で分析」「接続テスト」を押したときだけです。バッジの状態の確認は、保存された設定と権限を見るだけで、通信しません。

### 再分析しても入力されない欄は

手入力で大丈夫です。JushoAI は入力済みの欄を壊しません。再分析で入力できるようになったフォームは、プレビューの「開発に報告する」から開発者に知らせられます。

### 対応してほしいフォームがあります

入力できなかったフォームは、ページ下部の導線から GitHub の Issue で知らせてください。フォームの URL と、入力されなかった欄を書いていただけると、確認しやすくなります。

### TSV ファイルの扱いに注意はありますか

表計算ソフトで開いても数式が実行されないよう、`=` `+` `-` `@` で始まる値の先頭には `'` を付けます。ファイルにはページのアドレスが含まれるため、扱いは利用者の責任で行ってください。

### API キーを変えたい・消したい

設定ページで入力し直すと置き換わり、「保存済みの API キーを削除する」にチェックを入れて保存すると削除できます。ベース URL のオリジンを変えると、保存済みの API キーは引き継がれません。

### 保存すると「接続先が内部ネットワークのアドレスに解決されるため指定できません」と出る

OpenAI 互換 API のベース URL のホスト名が、内部ネットワークのアドレス（NAT64 や 6to4 の IPv6 変換プレフィックスを含む）に解決されています。nip.io・sslip.io のように、入力した名前自体は公開でも、解決先が内部アドレスになる名前は保存できません。公開のエンドポイントを指定してください。「接続先のアドレスを解決できなかったため、指定できません」と出るときは、リゾルバ（`dns.google`）に到達できない・名前解決ができないため、設定は保存されません。`dns.google` がネットワークで塞がれている環境では、接続先を検証できないため保存も呼び出しも行われません。

### 似たプロファイルを効率よく作りたい

「このプロファイルを複製」でコピーして、違う項目だけ直せます。

### 家族で同じ住所を使いたい

住所の「使うプロファイル」を「共通（どのプロファイルでも使う）」にすると、どのプロファイルでも候補になります。

### 英語住所はどう登録するのか

住所の「英語住所（任意）」に、国名、建物名、番地、市、州・地域、英語の郵便番号を半角英数で入れます。英語の欄があるフォーム用です。

### 内蔵 AI の準備に時間がかかる

モデルのダウンロードは、「JushoAI で入力」を押すと試みます。ブラウザによっては、自動では始まりません。バッジが「AI 未準備」「AI 準備中」の間は、完了を待ちます。

### ボタンが複数出る

「JushoAI で入力」は、見つけたフォームごとに出ます。入力したいフォームの近くのボタンを押してください。

### 対応ブラウザは

Chrome、Edge、Firefox（128 以上）に対応しています。Chrome ウェブストア、Edge アドオン、Firefox アドオン（AMO）で公開しています。Firefox ではブラウザ内蔵 AI は使えません。

### 監査ログの期間を変えたい

7 日間で固定されており、変えられません。「ログを削除」で、いつでもすべて削除できます。

### インターネットなしで使えますか

AI を設定していなければ、外部への通信はなく、ルールだけで動きます。外部の AI プロバイダを使う設定では、通信が必要です。

### 報告に住所や名前を書く必要はありますか

ありません。Issue は公開されるため、個人情報は書かないでください。プレビューの報告で送られるのは入力欄のメタデータ（または結果件数の内訳）だけで、プロファイルの値や欄に入っている値は送りません。
