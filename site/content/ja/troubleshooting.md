# トラブルシューティング

## バッジの状態と対処

バッジを押すと、状態に応じた案内が開きます。設定が必要な状態では、「AI 設定を開く」ボタンがあります。

| バッジ | 状態 | 対処 |
|---|---|---|
| AI: オフ | プロバイダが「使わない」です。 | 使う場合は、設定ページでプロバイダを選びます。 |
| AI 未設定 | 設定が不足しています（ベース URL、モデル名、API キーなど）。保存済みの API キーが復号できない場合も、この表示です。 | 設定ページで入力し直します。 |
| AI 権限なし | 通信の許可がありません。 | 設定ページで保存し直し、許可します。 |
| AI 認証エラー | プロバイダが認証を拒否しました。 | API キーを確認します。Ollama などローカルの場合は、`OLLAMA_ORIGINS` を確認します。 |
| AI: OpenAI 互換 / AI: Gemini | 利用できます。 | 不要です。 |
| AI 有効 | ブラウザ内蔵 AI が利用できます。 | 不要です。 |
| AI 未準備 | 内蔵 AI のモデルが未ダウンロードです。 | 「JushoAI で入力」を押すと、ダウンロードを試みます。 |
| AI 準備中 | 内蔵 AI のモデルをダウンロード中です。 | 完了を待ちます。 |
| AI 無効 | 内蔵 AI が使えません（フラグ、端末の条件、非対応のブラウザなど）。 | バッジを押して案内を見ます。フラグを確認します。 |

## AI がうまく動かないとき

まず、設定ページで「接続テスト（保存済みの設定で実行）」を試します。保存してから実行してください。

- 認証に失敗する: API キーを確認します。
- Ollama で 403 になる: Ollama 側の `OLLAMA_ORIGINS` に、`chrome-extension://<拡張機能の ID>` を許可します。
- 拒否される: モデル名と、モデルが JSON 形式の出力に対応しているかを確認します。
- 接続に失敗する: URL、モデル名、ネットワークを確認します。
- 通信が許可されていない: 設定ページで保存し直し、許可します。
- ブラウザ内蔵 AI が無効: フラグを有効にして、ブラウザを再起動します。設定は [AI プロバイダの設定](/guides/ai-providers/) にあります。

## 入力されない、おかしいとき

- 「JushoAI で入力」が出ない: text・email・tel・search の入力欄と select が 3 つ以上あり、そのうち 2 つ以上を判定できるフォームだけに出ます。非表示の欄は数えません。
- 設定ページが開く: プロファイルと住所（1 件以上）が未登録です。
- 欄に入力されない: 注記が付いていない欄にだけ入力します。入力済み、文字数超過、選択肢なしの欄には、プレビューに注記が付きます。`readonly` と `disabled` の欄は飛ばします。
- 対応していない欄がある: チェックボックス、ラジオ、日付などは対象外です。判定できない欄には入力しません。
- 郵便番号が最後に入る: 住所を自動補完するフォームとの競合を避けるためです。

判定の詳細は [対応するフォームと仕組み](/guides/how-it-works/) を参照してください。

## よくある質問

### AI を使わなくても動きますか

動きます。欄の判定はルールで行います。AI は、ルールで判定できない欄の分類だけに使います。AI を設定しない限り、外部への通信はありません。

### 何が送られますか

ブラウザ内蔵 AI 以外の AI プロバイダを設定した場合だけ、ルールで判定できない欄のメタ情報（欄を区別するための内部 ID、`name`、`htmlId`、label、placeholder、見出し、`type`、`maxLength`）を送ります。プロファイルの値は送りません。label や見出しはページ上の文言なので、表示されている個人情報が含まれることがあります。通信は「JushoAI で入力」を押したときだけです。詳しくは [プライバシーと送信データ](/guides/privacy/) を参照してください。

### 誤入力が心配です

入力前にプレビューで、欄と値を確認できます。入力するのは、プレビューで注記が付いていない欄だけです。入力済みの欄は上書きせず、最大文字数を超える値は入力しません。

### どのフォームで使えますか

text・email・tel・search の入力欄と select が対象で、判定できる欄が 2 つ以上ある、入力欄が 3 つ以上のフォームです。生年月日や性別などは扱いません。

### Ollama で 403 になります

Ollama は、`OLLAMA_ORIGINS` で許可していない限り、拡張機能のオリジンからの要求を 403 で拒否することがあります。`OLLAMA_ORIGINS` に `chrome-extension://<拡張機能の ID>` を許可してください。
