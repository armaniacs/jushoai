# 対応するフォームと仕組み

## 全体の流れ

1. 氏名・住所などの入力欄が複数あるフォームを見つけ、「JushoAI で入力」を出します。
2. ボタンを押すと、各欄をルールで判定します。
3. 判定できない欄だけ、設定した AI に分類させます。
4. 欄ごとに値を作り、プレビューに一覧を出します。
5. 「入力する」を押すと、プレビューで注記が付いていない欄にだけ入力します。

使い方は [はじめに](/guides/getting-started/) にあります。

## 欄の判定（ルール）

欄の判定は、次の順に見るルールで行います。

1. `autocomplete` 属性
2. `name` と `id`
3. label と placeholder
4. 見出し（`th`・`dt`・`legend`）

## AI の役割

ルールで判定できない欄だけを、設定した AI に分類させます。AI は分類だけを行い、入力する値は作りません。送る情報は [プライバシーと送信データ](/guides/privacy/) にあります。

## 値の作り方

- 氏名: 姓・名が別の欄なら、そのまま入れます。1 つの欄なら、例示（placeholder）から、全角スペース、半角スペース、詰めるのどれかを選びます。判断できなければ、半角スペースです。
- フリガナ: 全角カタカナで保持します。欄の例示や説明に合わせて、ひらがな、半角カナ、全角カナに変換します。
- 電話番号・郵便番号: 1 欄か分割欄か、ハイフンの有無を、例示と最大文字数から決めます。電話番号は、桁数で市外局番などを分けます。
- 住所: 都道府県・市区町村・番地・建物名が別の欄でも、1 つの欄でも対応します。建物名の欄がない場合は、番地の後ろに半角スペースで続けます。
- 都道府県のプルダウン: 「東京」「東京都」のような表記ゆれと、数字のコードの値も照合します。

## 入力の安全策

- 入力済みの欄は、上書きしません。
- 最大文字数を超える値は、切り詰めません。警告して、入力しません。
- `readonly` と `disabled` の欄は、飛ばします。
- プレビューを開いている間に自分で入力した欄は、上書きしません。
- 郵便番号の欄は、最後に入力します。

## 対応していない欄

対応するのは、text・email・tel・search の入力欄と、select です。それ以外の、チェックボックス、ラジオ、日付などは対応していません。

判定できない欄には、入力しません。生年月日などは扱いません。性別は select のみ対応し、ラジオボタンには入力しません。
