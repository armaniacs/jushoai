# 1 欄入力・取り込み・移行と管理

フォーム全体を一括で埋めるだけでなく、1 つの欄だけを狙って入れたり、入力済みのフォームから登録内容を取り込んだり、環境間でデータを移したりできます。

## 1 つの欄だけに入力する

フォーム全体ではなく、カーソルを置いた 1 つの欄だけを埋めたいときの方法です。

- 入力欄にカーソルを置いて、`Alt+J` を押します。
- 入力欄を右クリックして、「JushoAI: この欄に入力」を選びます。

どちらも AI は使わず、ルール（フリガナの変換を含む）、このサイトで覚えた対応付け、同じタブ内の複数ページ引継ぎを使って判定します。

- 入力する前に必ず確認用の「この欄に入力」パネルが開き、「注入する」を押すまで入力しません（「キャンセル」や Esc キーで閉じられます）。
- すでに値が入っている欄、`readonly` / `disabled` の欄、最大文字数を超える値や `pattern` に合わない値、該当する選択肢がないプルダウン、値が未登録の欄、判定できない欄には入力せず、「この欄には入力できません」パネルに理由を表示します。
- 「起動しないURL」に登録されたページでは動きません。

## 設定ページの構成

設定ページの左のメニューから、次の画面に移れます。登録や記録がある項目には、現在の保存件数（例: `プロファイル (2)`）が表示されます。

| 画面 | できること |
|---|---|
| プロファイル | 氏名、フリガナ、生年月日、学校・勤務先、メール、電話番号の登録 |
| 住所 | 住所・英語住所の登録 |
| AI 判定 | AI プロバイダの設定、接続テスト |
| 起動しないURL | JushoAI を動かさないページの登録 |
| 覚えた対応付け | プレビューの「直す」で教えた欄の意味の確認と削除 |
| 通信の監査ログ | AI の呼び出し記録の確認、TSV ダウンロード、削除 |

左メニューの下部には「不具合報告」のリンクがあり（`公開 issue が開きます。値は送りません`）、拡張機能のバージョンだけを入れた公開の GitHub Issue 作成画面を開けます。

## フォームから取り込む

プロファイルと住所の画面にある「フォームから取り込む」を押すと、開いているタブのフォームに入っている値から、登録内容の下書きを作れます。ブラウザが自動入力した値も取り込めます。

- フォームを開いているタブを選び、設定ページの「フォームから取り込む」を押してください（ルールのみで処理し、外部には送信しません。「起動しないURL」のページからは取り込みません）。
- フリガナの欄も判定して、プロファイルの「セイ」「メイ」の下書きに入ります。
- 形式と検証に合う値だけが下書きになります。
- 最初のカードが空のときはそこに入り、すでに値があるカードは上書きせず、新しいカード（`新規`）を作ります。
- 取り込める項目がないときや失敗したときは、空のカードが余分に残ることはありません。
- 「保存」を押すまで、ストレージには保存されません。

## エクスポートとインポート

プロファイルと住所を 1 つの JSON ファイルに書き出し、別の環境へ取り込めます。ブラウザの入れ替えや、Firefox の一時的なアドオンを終了して再登録するときに便利です。

- 「JSON でエクスポート」で書き出すファイルには、プロファイルと住所が平文で入ります。書き出し前に確認が出るので、ファイルの取り扱いには注意してください。
- 「JSON をインポート」で取り込むと、同じ ID のプロファイル・住所は上書きされ、新しい ID は追加されます。上限はそれぞれ 10 件までで、検証に通らないデータは保存されません。
- 取り込みの前に確認ダイアログが出ます。編集中の未保存の入力は破棄されます。
- 5 MB を超えるファイルは取り込めません。

## 覚えた対応付けを使う

ルールで別の意味に判定された欄や判定できなかった欄は、プレビューから正しい意味を教えられます。

1. プレビューで対象行の「直す」を押します。
2. 「この欄の意味を直す」が開くので、「意味」のプルダウンから正しい分類を選びます。
3. このサイトで次回以降も使いたいときは「このサイトに覚えさせる」にチェックを入れたまま（既定でオン）、「決める」を押します。

教えた対応付けはそのドメインに保存され、次の分類から優先して使われます。さらに、**「直す」で教えた欄は AI への送信対象から自動的に除外される**ため、AI を使う設定にしていても、その欄のメタデータは外部に送られません（[プライバシーと送信データ](./privacy.md)）。

覚えた内容は、設定ページの「覚えた対応付け」で一覧を確認したり行ごとに削除したりできます（最大 500 件）。表示・保存するのはドメイン、欄の特徴（`name` または `id`）、分類名だけで、プロファイルの値は含みません。削除すると、次の分類から元の判定に戻ります。

## 入力を取り消す

入力した直後は、結果画面の「元に戻す」で、JushoAI が入れた欄だけを元の空状態に戻せます。あとから自分で書き足した欄は保護のため触りません。詳しくは [安全のための仕組み](./safety.md) を参照してください。
