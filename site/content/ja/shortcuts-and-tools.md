# 便利な使い方

## 1 つの欄だけに入力する

フォーム全体ではなく、1 つの欄だけを埋めたいときの方法です。

- 入力欄にカーソルを置いて、Alt+J を押します。
- 入力欄を右クリックして、「JushoAI: この欄に入力」を選びます。

どちらも、AI は使わず、ルールだけで欄を判定します。入れる値は、確認用のパネルに出ます。パネルで確認するまで入力しません。入力済みの欄、読み取り専用の欄、文字数を超える値には入力せず、理由を表示します。起動しない URL では動きません。

## 設定ページの構成

設定ページの左のメニューから、次の画面に移れます。

| 画面 | できること |
|---|---|
| プロファイル | 氏名、フリガナ、メール、電話番号の登録 |
| 住所 | 住所の登録 |
| AI 判定 | AI プロバイダの設定、接続テスト |
| 起動しないURL | JushoAI を動かさないページの登録 |
| 覚えた対応付け | プレビューの「直す」で教えた欄の意味の確認と削除 |
| 通信の監査ログ | AI の呼び出し記録の確認、ダウンロード、削除 |

## フォームから取り込む

プロファイルと住所の画面にある「フォームから取り込む」を押すと、開いているタブのフォームに入っている値から、登録内容の下書きを作れます。ブラウザが自動入力した値も使えます。

- フォームを開いているタブで押してください。
- 形式に合う値だけが、下書きになります。
- 最初のカードが空のときはそこへ入り、すでに値があるカードは上書きせず、新しいカードを作ります。
- 「保存」を押すまで、何も保存しません。

## エクスポートとインポート

プロファイルと住所を JSON ファイルに書き出し、別の環境へ取り込めます。ブラウザの入れ替えや、Firefox の一時的なアドオンで再登録するときに便利です。

- 書き出したファイルには、プロファイルと住所が平文で入ります。取り扱いには注意してください。
- 取り込むと、同じ ID のプロファイル・住所は上書きされ、新しい ID は追加されます。それぞれ 10 件までです。
- 取り込みの前に確認が出ます。未保存の入力は破棄されます。
- 5 MB を超えるファイルは取り込めません。

## 覚えた対応付けを使う

プレビューで欄の意味を「直す」と、JushoAI はそのドメインでの対応付けを覚えます。次の分類から、同じ欄はその意味で扱います。覚えた内容は、設定ページの「覚えた対応付け」に出ます。行ごとに削除でき、削除すると次の分類から元の判定に戻ります。表示するのは欄の特徴と種類だけで、プロファイルの値は含みません。

## 入力を取り消す

入力した直後は、プレビューの「元に戻す」で、JushoAI が入れた欄だけを元に戻せます。仕組みは [安全のための仕組み](/guides/safety/) を参照してください。
