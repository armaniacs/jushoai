# PBI: URL最小化に戻り値ブランド型を付ける

## ユーザーストーリー

開発者として、監査用URLと公開用URLを取り違えられないようにしたい、なぜなら最小化ポリシーが3関数に分かれており、呼び出し側の選択を型が止めないため（統合自体は用途別差異のため行わない）。

## 優先度

- 順位: 3位 / 4件
- RICEスコア: 10（Reach=2 / Impact=0.5 / Confidence=80% / Effort=0.08人月）
- 根拠: 混入防止の保険。61・62とは独立でいつでも実施可。

## BDD受け入れシナリオ

```gherkin
Scenario: 公開報告に監査用URLが混ざらない
  Given 監査用に最小化したURLがある
  When 公開issueの本文に渡そうとする
  Then 型エラーになり、混入がコンパイル時に止まる

Scenario: 既存の呼び出しが壊れない
  Given 3つの最小化関数の既存呼び出しがある
  When ブランド型を付ける
  Then 振る舞いが変わらず、既存テストが緑のまま
```
