# PBI: バナーのXボタンで一時非表示にする

## ユーザーストーリー
JushoAI利用者として、邪魔な青バナーをその場で消したい、なぜなら資料共有やプレゼン中にバナーが視界に入るから

## ビジネス価値
- 中断の削減: プレゼン中に設定画面を開かずに消せる
- 測定方法: X押下で押したバナーが消え、リロードで戻ることを手動と単体テストで確認する

## BDD受け入れシナリオ

```gherkin
Scenario: Xを押したバナーだけが消える
  Given フォームに青バナーが出ている
  When 右上のXを押す
  Then 押したバナーだけが消え、他のバナーは残る

Scenario: リロードで戻る
  Given Xで隠したバナーがある
  When タブをリロードする
  Then バナーが再表示される

Scenario: 元に戻すで復活する
  Given Xで隠した直後のダイアログが開いている
  When 元に戻すを選ぶ
  Then 隠したバナーが再表示される
```

## 受け入れ基準
- [ ] Xは半透明の丸ボタンで、バナー右上に重なる
- [ ] Xはキーボードでフォーカスして実行できる
- [ ] 押した分だけ消え、別フォームのバナーに波及しない
- [ ] リロードで再表示される(永続化しない)
- [ ] `make check` が緑のまま

## テスト戦略(t_wadaスタイル)

### E2Eテスト
- なし(既存の samples 回帰網を使う。手動確認は設計書の手順どおり)

### 統合テスト
- `sync()` が隠し集合の分をマウントしないこと

### 単体テスト
- 隠し集合の追加と削除、別コンテナへの非波及
- ドラッグ後の誤クリック抑止がXにも効くこと

## 見積もり
3(小規模。UI追加1点とタブ内メモリ1点)

## 技術的考慮事項
- 依存関係: なし。永続除外の `stop()` とは混ぜない
- テスタビリティ: 隠し集合は純粋な集合操作として切り出す
- 非機能要件: 保存・送信・監査ログに残さない

## 実装者向け注記

### 現状コードの確認
```bash
grep -n "mountButton\|suppressClick" src/ui/button.ts
grep -n "planMounts\|mounted" src/entrypoints/content.ts
```
→ Xボタンは未実装。ドラッグ抑止の流用点を確認する

### 実装手順
1. `src/content/dismiss-memory.ts` を足す(集合の追加・削除・判定)
2. `src/ui/button.ts` に `onDismiss` とXボタンを足す
3. `content.ts` の `sync()` で集合分を除外する
4. 単体テストを先に書いてから実装する

### 落とし穴
- ドラッグとクリックの区別を壊さないこと
- `host.remove()` 後の再マウントで二重登録しないこと
