# PBI: Firefox for Android で動くことを確認し、対応を公表する

## ユーザーストーリー
スマートフォンで申込みフォームを埋める利用者として、Android の Firefox でも JushoAI を使いたい、なぜなら行政や学校の申込みはスマートフォンから行うことが多いのに、モバイルでは日本式フォームの手入力が特に面倒だから

## 区分
将来機能 / 1.0 後

## 優先度
- 順位: 15 / 17
- RICEスコア: 3 (Reach=15 / Impact=2 / Confidence=50% / Effort=4人週)
- 根拠: manifest は `strict_min_version` 128 で、web-ext lint は Android 142 に言及しているが、Android での動作確認・UI（浮遊ボタン、プレビュー、タッチ操作）の検証が無い。設定ページの操作性とタッチ配置の作り直しが要る見込みで工数が大きい
- 着手条件: モバイルでの利用要望が観測されたら、または正式版の安定後のロードマップ見直し時

## BDD受け入れシナリオ

```gherkin
Scenario: Android で 1 回の入力が完了する
  Given Firefox for Android に拡張を入れ、プロファイルを登録した
  When  申込みフォームでボタンをタップし、プレビューで「入力する」をタップする
  Then  欄が埋まり、画面幅に収まった結果画面が出る

Scenario: 未対応の機能は明示する
  Given Android では使えない機能（右クリックメニューなど）がある
  When  利用者がガイドを読む
  Then  使えない機能と代わりの操作が書かれている
```

## 受け入れ基準
- [ ] 実機（または Android エミュレータ）で主要シナリオを確認し、結果を記録
- [ ] AMO の Android 対応フラグと manifest の `gecko_android` 設定を決める
- [ ] 狭い画面でのプレビュー・設定ページの配置を直す
- [ ] ガイドに Android の節を追加
