# PBI: saveDataに容量・競合ガードを付ける

## ユーザーストーリー

利用者として、QUOTA超過や同時保存でプロファイル追加が黙って消えないようにしてほしい、なぜなら保存したはずのプロファイルが消えていると住所入力の手間が無駄になるため。

## 優先度

- 順位: 23位 / 40件
- RICEスコア: 83（Reach=10 / Impact=2 / Confidence=50% / Effort=0.12人月）
- 根拠: 保存失敗の黙殺をなくしデータ消失を防ぐ。依存なし（PBI-35・29と同storage.tsのため実装は直列）。
- 出典: checking-team Data Integrity Medium
- 対象: src/storage.ts:101-103

## BDD受け入れシナリオ

```gherkin
Scenario: 容量超過時は例外を握りつぶさず保存失敗を表示する
  Given プロファイル編集中の状態である
  When saveDataでQUOTA超過エラーが発生する
  Then 例外が呼び出し元に伝わり、UIに保存失敗が表示され、黙って成功扱いにならない

Scenario: 同時保存時は保存直前に再読込して上書きロストを防ぐ
  Given 2つのコンテキストで同時にプロファイル追加が行われる
  When saveDataが保存直前に最新データを再読込してマージする
  Then 後勝ちの全上書きで先行追加が消えることがなく、両方の追加が残る
```
