# PBI: 英語ヘルプ最小限の併記の方針決定と実装

## ユーザーストーリー
日本在住の非日本語話者として、日本語フォームでJushoAIの使い方が英語で分かってほしい、なぜならUI日本語専用では住所・氏名の登録手順で詰まり使えないから。ドキュメントは日英なのにUIだけ日本語のみというねじれもある

## 優先度
- 順位: 5 / 6
- RICEスコア: 180（Reach=150 / Impact=1 / Confidence=60% / Effort=0.5人週）
- 根拠: 対象は狭いが工数小。UI日本語専用の意図的仕様と衝突するため方針決定が先行条件。依存は方針決定のみ

## BDD受け入れシナリオ
Scenario: 英語話者が登録手順にたどり着ける
  Given 日本語を読めない利用者
  When popup・設定のヘルプを開く
  Then 最小限の英語ガイド（登録→入力→承認の3手順）が見える

Scenario: 日本語UI方針を崩さない
  Given 日本語利用者
  When 通常に使う
  Then 既存の日本語表示・操作は変わらない
