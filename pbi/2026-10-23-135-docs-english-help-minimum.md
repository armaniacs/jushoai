# PBI: 英語ヘルプ最小限の併記の方針決定と実装

## ユーザーストーリー
日本在住の非日本語話者として、日本語フォームでJushoAIの使い方が英語で分かってほしい、なぜならUI日本語専用では住所・氏名の登録手順で詰まり使えないから。ドキュメントは日英なのにUIだけ日本語のみというねじれもある

## 優先度
- 順位: 5 / 6
- RICEスコア: 180（Reach=150 / Impact=1 / Confidence=60% / Effort=0.5人週）
- 根拠: 対象は狭いが工数小。UI日本語専用の意図的仕様と衝突するため方針決定が先行条件。依存は方針決定のみ

## BDD受け入れシナリオ
Scenario: 英語話者が登録手順にたどり着ける
  Given 日本語を読めない利用者
  When popup・設定のヘルプを開く
  Then 最小限の英語ガイド（登録→入力→承認の3手順）が見える

Scenario: 日本語UI方針を崩さない
  Given 日本語利用者
  When 通常に使う
  Then 既存の日本語表示・操作は変わらない

## 受け入れ基準
- [x] 方針を`00-INDEX.md`または該当PBIに記録する（全面英語化か最小併記か） → **最小併記**に決定。UIは日本語専用の意図的仕様を維持し、popupの末尾に英語ガイド（登録→入力→承認の3手順）を追記するだけ。全面英語化は行わない（本実装記録が方針の記録）
- [x] 日英サイトの対応検査（H2数・文言キー）を壊さない → `make site` exit 0（26ページ、site check passed）。popupはサイトビルドの外なので対応検査に影響しない
- [x] 追加文言の対応表を更新する → ガイド内で日本語キー語（設定・入力する）に英語説明を併記（`設定 (Settings)`・`入力する (Apply)`）。サイトのi18n JSON（15キー・日英同数）は変更なし

## 実装記録（2026-10-23）

- `src/entrypoints/popup/main.ts`: popupの末尾に「How to use / 使い方（English）」セクションを追加。登録（設定で氏名・住所を登録）→入力（フォームページでJushoAIボタンを押す）→承認（プレビュー確認後に入力する）の3手順。日本語セクションは先頭のまま一切変更しない（BDDシナリオ2「日本語UI方針を崩さない」）。
- `src/entrypoints/popup/index.html`: `.guide-wrap`（上罫線で区切り）と`.guide li`（罫線なし・薄めの表示）のスタイル。
- 方針の記録（受け入れ基準1）: UI日本語専用は意図的仕様。最小併記（popup末尾の追記のみ）を採用し、全面英語化・言語切替は行わない。
- テスト: `tests/entrypoints/popup.test.ts`に英語ガイドの表示・3手順の文言・日本語セクションの維持の1件追加。
