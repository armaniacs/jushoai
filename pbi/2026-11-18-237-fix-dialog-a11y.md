# PBI: 非表示・クイック登録ダイアログの a11y（フォーカス・告知・Esc・復帰）

## ユーザーストーリー
スクリーンリーダー・キーボードの利用者として、バナーの X から開くダイアログにフォーカスが移り、出現が告知され、Esc で閉じられてほしい、なぜなら 現状は開いてもフォーカスされず aria-live もなく、X 押下でバナーごと破棄されてフォーカスが body に落ち、15 秒の自動クローズと重なると undo も「起動しないURL」登録も非視覚ユーザーだけが到達できないから

## BDD受け入れシナリオ
Scenario: 開いたらフォーカスされ、告知される
  Given バナーの X を押した直後である
  When  ダイアログが開く
  Then  最初のボタンにフォーカスが移り、出現が role="status"（aria-live="polite" 相当）で告知される

Scenario: Esc で「今回だけ閉じる」相当に閉じる
  Given ダイアログにフォーカスがある
  When  Escape を押す
  Then  dismiss の「今回だけ閉じる」と同じ経路で閉じる（登録は起こらない）

Scenario: 閉じた後にフォーカスが合意位置へ戻る
  Given ダイアログを（X 押下・Esc・自動クローズのいずれかで）閉じた
  When  フォーカスの復帰先を確認する
  Then  フォーカスは body ではなく page 側の合意位置（バナー破棄前の位置を復元できないため合意した要素）へ戻る

Scenario: フォーカス中のタイマー保持が確実に効く
  Given キーボードでダイアログ内にフォーカスがある
  When  15 秒が経過する
  Then  自動クローズは行われず、フォーカスを外した時点で保持が解けてクローズする

## 受け入れ基準
- [ ] ダイアログ表示時に最初のボタンへ focus() が移る
- [ ] 出現が live region（role="status" または aria-live="polite" の兄弟領域）で告知される
- [ ] attachEscapeClose と同種の Esc 閉じが付き、Esc は「今回だけ閉じる」（onClose）に振るえ
- [ ] 閉じた後のフォーカス復帰先が panel.ts の作法と同じ方針で定義され、body 落ちが起きない
- [ ] フォーカス中（focusin 済）のタイマー停止が unit テストで固定される
- [ ] 自動クローズ予定が利用者に分かる（本文明示または残秒表示。スクリーンリーダーにも読める形で）
- [ ] `make check` が緑

## 実装手順
