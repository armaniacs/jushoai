# PBI: 分割不一致時の完全値重複注入を止める

## ユーザーストーリー

フォーム利用者として、電話3分割・郵便2分割に一致しない欄に同じ完全番号が3欄複製されないようにしてほしい、承認後に重複注入されるため。

## 優先度

- 順位: 9位 / 20件
- RICEスコア: 400（Reach=30 / Impact=2 / Confidence=80% / Effort=0.12人月）
- 根拠: 分割不一致群への完全値複製の遮断。依存なし。
- 出典: checking-team Domain Logic Medium、src/core/classify-rules.ts:350-356、src/core/planner.ts:60-70

## BDD受け入れシナリオ

```gherkin
Scenario: 分割不一致群はunknown化または2分割扱いで複製されない
  Given 電話3分割・郵便2分割のいずれにも一致しない欄群がある
  When 分類・計画が実行される
  Then 不一致群はunknownに落ちるか2分割扱いに留まり、同じ完全番号が3欄に複製されない

Scenario: 正常分割は従来通り注入される
  Given 電話3分割・郵便2分割に正しく一致する欄群がある
  When 分類・計画が実行される
  Then 各分割欄に従来通りの分割値が注入される
```

- 回帰: 正常な電話3分割・郵便2分割の既存注入が維持されることを確認する
