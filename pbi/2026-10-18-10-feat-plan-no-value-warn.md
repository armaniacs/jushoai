# PBI: プロファイル欠落欄をwarn-no-valueで可視化する

## ユーザーストーリー

フォーム利用者として、値がなくて消えた欄を「分類失敗」と区別して知りたい、現状は行自体が消え原因不明のため。

## 優先度

- 順位: 10位 / 20件
- RICEスコア: 400（Reach=40 / Impact=1 / Confidence=80% / Effort=0.08人月）
- 根拠: 欠落欄の行消失と分類失敗を区別し、利用者の原因特定を助ける。依存なし。
- 出典: checking-team Domain Logic Medium、src/core/planner.ts:111-112

## BDD受け入れシナリオ

```gherkin
Scenario: 欠落欄は理由付きの行として残る
  Given プロファイルに値がない欄がある
  When プランが構築される
  Then 行自体は消えず、欠落理由付きで残る

Scenario: 正常値は従来通り適用される
  Given プロファイルに値がある欄がある
  When プランが構築される
  Then 従来どおりの値で適用される
```
