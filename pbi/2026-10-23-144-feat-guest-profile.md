# PBI: 使い捨てゲストプロファイル（保存しない1回利用）

## ユーザーストーリー
代理入力や一時利用をする人として、保存せず1回だけ使うプロファイルがほしい、なぜなら家族の代理入力のために常用プロファイルへ保存すると残ってしまい、消し忘れの事故になるから

## 優先度
- 順位: 8 / 8
- RICEスコア: 60（Reach=150 / Impact=1 / Confidence=60% / Effort=1.5人週）
- 根拠: 対象は狭いが代理入力の事故防止に効く。履歴・同期に残さない設計が条件

## BDD受け入れシナリオ
Scenario: 1回だけ使える
  Given ゲストプロファイルを入力中
  When プレビューで承認する
  Then その場だけ注入され、保存・履歴・同期には残らない

Scenario: 閉じれば消える
  Given ゲスト利用中
  When タブを閉じるか完了する
  Then ゲスト値は破棄され、常用プロファイル・住所に影響しない

## 受け入れ基準
- [ ] ゲスト値は`chrome.storage`に永続化しない（メモリのみ）
- [ ] 監査ログ・履歴・export/importに対象外として扱うか明記する
- [ ] `MAX_ITEMS=10`の常用枠を消費しない

## テスト戦略
- E2E: ゲスト入力→注入→破棄の通し確認
- 統合: 永続化されないことのテスト（再読込後に残らない）
- 単体: ゲストと常用の分離ロジックの単体テスト
