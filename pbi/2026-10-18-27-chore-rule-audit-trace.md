# PBI: ルールのみ動作の診断証跡を残す

## ユーザーストーリー

開発者として、ルール分類のみで完結した実行の件数・所要時間を現場で再現できるようにしてほしい、なぜなら現状はAI経路にしか計測点がなく、ルールのみ動作の診断証跡が残らないため。

## BDD受け入れシナリオ

```gherkin
Scenario: ルールのみ完結実行の件数と所要時間が1行に出る
  Given AI分類を使わない設定でフォームを解析する
  When classifyAllがルール分類のみで完結する
  Then console.debugに件数と所要時間を集約した1行が出力される

Scenario: 診断出力はバイト予算と保持期間を守る
  Given ルールのみ完結の診断出力が有効である
  When 繰り返し実行して診断を蓄積する
  Then バイト予算を超えず、保持期間を過ぎた診断は残らない
```

## 受け入れ基準

- [x] `classifyAll`のルールのみ完結実行で、件数・所要時間を集約した`console.debug`1行が出力される
- [x] 診断1行にプロファイルの値や欄の個人情報を含まない
- [x] 診断出力がバイト予算（監査エントリ上限等）を超えない
- [x] 保持期間を過ぎたルール側診断が残存しない
- [x] AI経路の既存計測点（`AuditedClassifier.log`）の挙動が変わらない

## テスト戦略

- 単体テスト: ルールのみ完結時に`console.debug`が件数・所要時間付きで1回だけ呼ばれることを確認する
- 単体テスト: 診断行に値・個人情報を含まず、バイト予算内に収まることを確認する
- 単体テスト: AI経路あり実行では従来の監査記録が変わらないことを確認する
