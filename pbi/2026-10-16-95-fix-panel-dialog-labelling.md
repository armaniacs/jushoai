# PBI: パネルdialogのラベル付けをclosed shadow境界越しに機能させる

## BDD受け入れシナリオ

```gherkin
Scenario: パネルを開くとダイアログ名が支援技術に伝わる
  Given フォームでプレビューを開く
  When パネルが表示される
  Then ダイアログに見出し由来のアクセシブル名が付く

Scenario: 見出しのないパネルでも無名にならない
  Given 見出しを持たない表示内容でパネルを開く
  When パネルが表示される
  Then 何らかのフォールバック名または警告なく扱われる
```
