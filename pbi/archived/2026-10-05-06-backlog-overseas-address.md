# PBI: 海外住所対応 — Country・Address-1〜4等の半角英数欄 (backlog)

## ユーザーストーリー
JushoAI利用者として、海外住所(Country・Address-1〜4・Postal code等)も半角英数で自動入力したい、なぜなら対象フォーム `https://www.joshibi.ac.jp/overseas/webform` にはName以外にも半角英数指定の住所欄が7項目あるから

## ビジネス価値
- 海外住所フォーム全体の入力手数を削減し、PBI-05の価値を完成させる
- 測定方法: 対象URL相当のフォームで全項目が半角英数で正しく入ること

## BDD受け入れシナリオ

```gherkin
Scenario: 海外住所欄に登録値が半角英数で入る
  Given プロファイルに海外住所が登録されている
  And フォームにCountry・Address-1〜4・Postal codeの半角英数欄がある
  When 利用者がJushoAIボタンを押してプレビューを承認する
  Then 各欄に対応する値が半角英数で入力される

Scenario: 未登録・不一致は触らない
  Given 対応する登録値がない、または選択肢・形式が一致しない
  When 利用者がプレビューを開く
  Then 該当欄は警告またはスキップで上書きされない
```

## 受け入れ基準
- [x] Country・Address-1(建物)・Address-2(番地)・Address-3(市)・Address-4(州/地域)・Postal code の解決ができる
- [x] 半角英数バリデーションとmaxlength対応ができる
- [x] 日本語住所からの自動翻字はしない(別途登録方式)。方式は実装時に決定する
- [x] 対象URL相当のサンプルで手動確認できる
