# PBI: ラベル別文言の電話・郵便番号分割に対応する

## ユーザーストーリー
JushoAI利用者として、欄ごとにラベル文言が違う電話・郵便番号の分割欄(市外局番/市内局番/加入者番号、上3桁/下4桁)にも自動入力してほしい、なぜならform-mailer系の実フォームで電話・郵便番号が空欄のまま残るから

## 優先度
- 順位: 01 / 2件
- RICEスコア: 30(Reach=30 / Impact=2 / Confidence=50% / Effort=1.0人週)
- 根拠: ユーザー価値が直接大きいためB先行(ユーザー指示)。候補Aの運用整備より先に着手する

## BDD受け入れシナリオ

```gherkin
Scenario: ラベル別文言の電話分割欄に入る
  Given プロファイルに電話番号が登録されている
  And フォームに電話番号の市外局番・市内局番・加入者番号の3欄がある
  When 利用者がJushoAIボタンを押してプレビューを承認する
  Then 3欄に対応する断片が入力される

Scenario: 別ブロックの欄には断片を入れない
  Given 注文者とお届け先など別ブロックに電話欄がある
  When 利用者がJushoAIボタンを押す
  Then 1つの値の断片が別ブロックに注入されない(現行の保護を維持)
```

```gherkin
Scenario: ラベル別文言の郵便番号分割欄に入る
  Given プロファイルに住所が登録されている
  And フォームに郵便番号の上3桁・下4桁の2欄がある
  When 利用者がプレビューを承認する
  Then 上3桁・下4桁に対応する断片が入力される
```
