# PBI: 監査ログを TSV でダウンロードできるようにする

状態: 実装済み（`make check` green。実機での確認とコードレビューはユーザー作業として残す）

## ユーザーストーリー
AI 判定を使う利用者として、監査ログをファイルで保存したい、なぜなら自分で内容を確かめたり、第三者に見せたりして透明性を検証したいから

## 優先度
- 順位: 2 / 2
- RICEスコア: 13.3（Reach=5 / Impact=1 / Confidence=0.8 / Effort=0.3）
- 根拠: 順位 1 のログがあって初めて意味を持つため、依存で後に置く

## 背景
- yasumaro（https://github.com/armaniacs/yasumaro）の「TSV でダウンロード」（`src/dashboard/utils/auditLogTsv.ts`）にならう。表計算で開いてフィルタ・集計できる
- 置き場所は設定ページの「AI 判定」セクション。ログの件数表示と削除ボタン（順位 1）の隣に置く
- ファイルは Blob と `a[download]` で作る。追加の権限（`downloads`）は要求しない

## 形式
- ファイル名: `jushoai-audit-log-YYYY-MM-DD.tsv`
- 列: `id` / `created_at`（ISO 8601）/ `provider` / `host` / `model` / `purpose` / `page_url` / `field_count` / `result` / `http_status` / `retried`
- 古い順ではなく、新しい順に並べる（yasumaro と同じ）
- 数式の実行を防ぐため、先頭が `=` `+` `-` `@` のセルには `'` を付ける。タブ・改行・引用符を含むセルは `"` で囲み、引用符は二重にする

## BDD受け入れシナリオ
Scenario: ログをダウンロードする
  Given 監査ログが 1 件以上ある
  When 設定ページで「TSV でダウンロード」を選ぶ
  Then 日付入りの `.tsv` が保存され、ヘッダ行とログが新しい順に 1 行ずつ入っている

Scenario: ログが空のとき
  Given 監査ログが 0 件
  When 設定ページを開く
  Then ダウンロードのボタンは無効で、ログがない旨が表示される

Scenario: 数式として実行されるセルの無害化
  Given ページ URL が `=HYPERLINK(...)` のように数式の先頭文字で始まるログがある
  When TSV をダウンロードして表計算ソフトで開く
  Then そのセルは文字列として表示され、数式は実行されない

Scenario: 保持期間についての表示
  Given ダウンロードのボタンの近くを見る
  When 説明文を読む
  Then ログは端末内に 7 日間だけ保存されること、ファイルの扱いは利用者の責任であることが書かれている
