# PBI: 最後のプロファイルも削除できるようにする

## ユーザーストーリー
利用者として、プロファイルが1件だけ残っている状態でも削除したい、なぜならお試しデータの入れ替えなど最初からやり直したいときに詰んでしまうから

## ビジネス価値
- 住所側（0件まで削除可）との不一致を解消し、設定画面の操作に迷いをなくす
- 測定: 削除ボタン無効に関する問い合わせ・報告の解消

## BDD受け入れシナリオ

```gherkin
Scenario: 最後の1件を削除できる
  Given プロファイルが1件だけある
  When その削除ボタンを押す
  Then カードが0件になり新規追加ボタンだけが残る
  And 削除ボタンは無効化されない

Scenario: 0件のまま保存はブロックされる
  Given プロファイルが0件
  When プロファイル画面で保存を押す
  Then 件数不足のエラーが出て保存されない

Scenario: 追加し直して保存できる
  Given プロファイルが0件
  When 新規追加して入力し保存を押す
  Then 保存が成功する
```

## 受け入れ基準
- [x] プロファイル1件の状態で削除ボタンが有効で、押すと0件になる
- [x] 0件では新規追加ボタンが有効のまま残る
- [x] 0件での保存は件数エラーでブロックされる（既存メッセージ）
