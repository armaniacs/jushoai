# PBI: 「AI で分析」への改名とポップアップボタンに合わせてドキュメントを直す

## ユーザーストーリー
ドキュメントを読む利用者として、ボタン名とガイドの表記が一致していてほしい、なぜなら「LLM で再分析」と書かれた手順では画面と見比べられず迷うから

## 優先度
- 順位: 3 / 3
- RICEスコア: 20.0（Reach=8 / Impact=0.5 / Confidence=1.0 / Effort=0.2）
- 根拠: スコア自体は順位2より高いが、順位1の改名と順位2のボタン仕様の両方に依存するため最後に置く（依存はスコアより優先）

## 背景
- 改名（`2026-10-06-07-feat-rename-to-ai-analyze.md`）とポップアップボタン（`2026-10-06-08-feat-popup-ai-analyze.md`）が画面を変えるため、ドキュメントが遅れると手順が食い違う
- 日英の見出し数が違うとサイトビルドが失敗する制約がある（`site/` の検査）。日英は必ず対で直す
- 設計書・計画書（`docs/superpowers/specs/*`、`docs/superpowers/plans/*`）と過去ブログ（`docs/blog/*`）は履歴のため書き換えない

  When 再分析の節を読む
  Then 日本語版と同じ内容が英語で書かれ、日英の H2 数が一致する
