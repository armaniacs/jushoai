# PBI: 監査ログの予算計上から区切り文字の分を正しく引く

状態: 未着手（0.1.14 コードレビュー 2026-10-12 の Suggestions #3 から起票）
起票日: 2026-10-12

## ユーザーストーリー

保守担当者として、容量計上の式が実際の保存サイズと一致していてほしい。なぜなら `withinByteBudget` は除去時に `sizes[i]` だけを引き、配列の区切り文字（1 件あたり 1 バイト）を引いていないため、除去後の合計が真の直列化サイズより最大 r バイト大きく見積もられるから。

## 優先度

- 順位: 4 / 全候補 5 件
- RICEスコア: 0.5（Reach=1 / Impact=0.25 / Confidence=100% / Effort=0.5）
- 根拠: 過大評価は安全側で、予算（4MB）に対する誤差は最大 1KB（0.025%）のため実害は無い。式が正確に見えることが誤読を招く点だけが問題。他候補と独立

## BDD受け入れシナリオ

```gherkin
Scenario: 除去後の合計が真の直列化サイズと一致する
  Given 予算を超える記録の並びがある
  When  予算に収まるまで古い記録を落とす
  Then  残った並びの見積もりは、その並びを JSON 化した実バイト数と一致する

Scenario: 予算内の並びは変更しない
  Given 予算に収まっている記録の並びがある
  When  計上する
  Then  どの記録も落とされない
```
