### [High] 非表示・クイック登録ダイアログが支援技術に実質到達不能
- 指摘者: Accessibility Advocate（関連: UI Expert のパネルライフサイクル迂回指摘・Timing Adjustable 指摘も同根）
- 場所: src/ui/dismiss-dialog.ts:43-70、src/entrypoints/content.ts:498-535
- 影響: ダイアログは開いてもフォーカスされず aria-live もなく、スクリーンリーダーに出現が告知されない。X 押下でバナーごと破棄されフォーカスが body に落ち、15 秒自動クローズと重なると undo も「起動しないURL」登録も非視覚ユーザーだけが到達できない。panel.ts の opener 復帰（panel.ts:54）という既存の作法が新規経路だけ素通し。Esc でも閉じられない
- 対処: 開いたら最初のボタンへ focus()、閉じたら合意位置へ復帰。出現を role="status" で告知。attachEscapeClose を付け Esc で「今回だけ閉じる」に振る。自動クローズ予定の明示または残秒表示

### [Medium] 除外リストの複数ライター競合: オプション画面の保存がバナー経由の登録を黙って巻き戻す
- 指摘者: Red Team Leader + Data Integrity Expert（重複統合）
- 場所: src/content/exclusion-register.ts:17-41（load→add→save の非原子 3 段階）、src/entrypoints/options/exclusion-section.ts:23-66（boot 時スナップショットの丸ごと書き戻し）、src/kv-store.ts:116-125
- 影響: 0.1.34 で除外リストに第 2 のライターが増えた。オプション画面を開きっぱなしの間ずっと競合ウィンドウが続き、「保存」でクイック登録が黙って消える（ユーザーは成功通知だけ見る）。ユーザーが明示同意したオプトアウト制御の消失
- 対処: オプション側の保存をマージ方式（保存時再読込して差分適用）にするか、storage.onChanged で開いている画面の entries を再同期。kv-store に世代タグ付き CAS を追加する案もあり

### [Medium] チャンク実行ループで run 合計タイムアウト予算（PBI-33）が失効し、非リトライ失敗後も全チャンク送出される

### [Medium] ページ支配下の pattern 属性を RegExp にコンパイルして content script 内で実行しており、ReDoS によるタブ凍結の起点になり得る
- 指摘者: Blue Team Leader

- 影響: PBI-210 の pattern 適合警告がページ入力を `^(?:...)$` でコンパイルし、buildPlan 時に `.test()` を実行。ネスト量子化の crafted pattern で指数バックトラックが起き得る。トリガは「攻撃者ページでバナー押下」のみで承認不要。影響は単一タブの凍結
